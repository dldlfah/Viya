## 1. 현재 확정된 디자인 방향
- [프로듀서 승인] 사용자가 '시안은 이걸로 확정하자'라고 지정한 **성숙한 비야의 캐릭터 디자인/제작 참고 시트**가 비주얼 기준이다. 해당 이미지는 본 대화에서 생성한 재수정 비야 시트(비야의 성숙한 실루엣과 노출 구조를 복원한 이미지).
- 유지해야 하는 정체성: 긴 짙은 갈색/흑갈색 웨이브 헤어, 성숙한 애니풍 얼굴, 매력적인 성인 여성 체형·가슴/허리/골반 라인, 아이보리 상의, 몸매를 살리는 검정 코르셋·부분 장갑, 금빛 금속장식, 짧은 하의·허벅지 스트랩, 긴 장화, 비대칭 진홍색 천, 룬 장식 총기.
- 화풍: 독자적인 고급 다크 판타지 애니 스타일. 단순 미려한 그림이 아니라 캐릭터 고유성과 소재 대비(아이보리/차콜/건메탈/황동/진홍)가 읽혀야 한다. 무분별한 실사화·SF 의상 교체·원화의 전반적인 덧가림 금지.
- 표현: 성인 캐릭터의 섹시함과 균형 잡힌 인체 비율, 움직임에서의 실루엣을 함께 유지한다.

## 3. 모델링 및 코스튬 교체 설계
- 신규 게임 캐릭터 제작은 원화 최종 승인과 실제 모델링 가능성을 분리한다.
- 하나의 **공통 신체 + 공통 스켈레톤**, 분리된 헤어·상의·코르셋·장갑·허리 장비·하의·스타킹·부츠·진홍 망토·무기 슬롯을 지향한다.
- 의상별 메시/스키닝/클리핑 문제는 별도 검증한다. 3D 생성 이미지만으로 파츠 교체 기능 완성을 선언하지 않는다.
- 3D 모델은 쿼터뷰 인게임 표현과 다르게 보일 수 있다. 캐릭터가 작게 보이는 모바일 화면에서 정체성이 살아나는지 실제 크기로 검수한다.
- [보류] 최종 인게임 표현을 실시간 3D로 할지, 3D 기반 2D 스프라이트로 출력할지는 모델 품질·기기 성능 비교 후 결정.

## 4. 아트 변경 규칙
1. 승인 원본 무변경. 새로운 스타일·옷·각도·표정은 별도 파일/버전으로 생산한다.
2. 같은 얼굴/체형/의상 구조를 유지하고 전후 비교 이미지를 남긴다.
3. 후면·측면과 가려진 의상 표면은 모델링 단계에서 필요한 곳만 보완하고, 무단 재설계 금지.
4. 시각 품질 최종 승인은 프로듀서가 판단한다. AI 자체 생성·기하 검증 통과는 최종 승인 아님.
