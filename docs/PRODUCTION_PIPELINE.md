2026-11-17 최신 프로듀서 지시로 **게임 우선 / 비야 시안 확정 후 보류**로 변경했다. 직전 원화 정합화·3D 블로킹 선행 흐름은 더 이상 활성 작업이 아니다.

## 단일 작업 예정 문서

**[PLANNED_WORK.md](PLANNED_WORK.md)**에 게임 제작 순서, 보류 원화 수정 방식, Higgsfield 모델/마스크·전후 검수, 모델링/코스튬 계획을 통합했다. 새 계획을 이 파일이나 현재 작업 문서에 중복 작성하지 않는다.

## 역할

Godot 게임 구현은 기존 승인 아트 완성과 분리해 진행한다. `run_state.gd`가 전투 상태를 소유하고 입력/표시는 분리한다. 임시 도형은 교체 가능한 전투 대역이며 정식 비야 디자인이 아니다. GitHub `dldlfah/Viya`가 작업 저장소이며 BREAKERS 본편은 변경하지 않는다.

Higgsfield 원화 작업은 보류한다. 재개 시에만 통합 예정 문서에 기록된 제한된 부위 편집 원칙과 비용 확인을 적용한다. 3D 파일 생성·리깅·코스튬 교체는 각각 다른 완료 단계이며 현재 완료된 것으로 취급하지 않는다.

## 검증

실제 소스·참조 경로·Godot 구문/타입·엔진 동작·렌더·모바일 실기·아트 승인을 분리한다. 현재 환경에서 수행하지 못한 검증은 `NOT_VERIFIED`로 남긴다. 매회 사용자 검수 요청이나 검증 문서 증식으로 실제 게임 제작을 대체하지 않는다.
