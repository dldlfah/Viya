## 3. 사용자 확정사항과 임시값

모바일 가로 서바이버, 전장 주력1명, 현재 실제 캐릭터 데이터는 비야다. 레벨업 후보는 **공통 공격8 + 캐릭터 공격1 + 공통 패시브8(저항 제외) + 캐릭터 필살기 강화1 = 18종**, 기본적으로 서로 다른 무작위3개 중1개 선택이다. 공통16종은 공유하고 전용2종/액티브 설정은 캐릭터 데이터로 교체한다. 시험용 fixture는 새 플레이 캐릭터가 아니다.

전 스킬명은 **`[임시]`**. 공격/패시브 보유 UI는 두 줄, 고유 액티브는 별도 버튼/PC F다. 마법 자체를19번째 후보로 추가하지 않는다. 요구XP는 `(10+(level-1)×6)×3`, 기본드롭5XP이며 획득량3배가 아니다. 서포터는 공격2칸·패시브2칸 **빈 자리만** 둔다.

동시 장착 공격4/패시브4, 시작 소총Lv.1, 강화상한5, 후보 동일확률, 개별 효과/수치·전장·적·마법 자원·연출 시간은 임시다. 후보8종을 장착8칸으로 해석하지 않는다. 비야 ART-001 시안 확정 이후 원화·3D·리깅·코스튬은 보류하며 게임 선행조건이 아니다. 수집·뽑기·경제·서포터 효과를 임의 확대하지 않는다.

## 6. 현재 기능

### 6.1. 전투·한 판 흐름

READY/RUNNING/PAUSED/DEFEAT/CHOOSING/ABANDONED를 구분한다. 출격은 캐릭터 후보/마법 검증 후 위치·HP·통계·적/탄환/픽업/효과·성장/마법/반응을 초기화한다. 알 수 없는 캐릭터를 비야로 조용히 바꾸지 않는다. 이동·경계·적추적·최근접 자동사격·선분 탄환 충돌·관통 중복 방지·피격무적을 유지한다.

새 전투/포기는 확인 후에만 초기화/종료한다. 취소는 같은 후보/ticket과 상태를 보존한다. 포기는 HP0 패배와 별도이며 고정 결과를 복사한다. 결과→대기에서 시간을 진행하지 않고 새 출격 전 결과를 유지한다. 확인 중 앱 중단은 PAUSED, 낡은 메뉴 요청은 navigation_ticket/menu_revision으로 거절한다.

### 6.3. 마법·상태반응·실제 결과 표시

`viya_crimson_wave`/[임시] 진홍 파동은 버튼/F→소유자/상태/ticket/MP/쿨다운 검사→자원1회 차감→범위피해→기존 처치/XP→HUD다. 강화0부터 사용하고 강화 선택이 MP/쿨다운을 초기화하지 않는다. 빈 곳 발동/소비는 임시 정책이다. 이동/마법 손가락은 별개이며 정지·선택·확인·결과·대기에서는 사용/시간이 차단된다.

반응은 종료>피격>마법>레벨업>저체력>기본, 가려진 하위 반응은 시간보존, 저체력은 별도경고다. 현재 문구/테두리 대역이지 표정 원화가 아니다.

CombatCues는 실제 HP차감 뒤 숫자/치명타, 적제거 뒤 흔적, 픽업흡수/XP부여 뒤 +XP를 기록한다. 과잉피해 제외·기존 치명타 결과 재사용·드롭/임의XP를 수집성공으로 오표시하지 않는 원칙을 유지한다. 표시 상한 초과 시 표시만 버리고 전투/보상은 유지한다.

### 6.4. 모바일·조회·선택 전후 비교

공유배치/compact/안전영역·카드3열 또는1열스크롤·리사이즈 입력해제를 유지한다. 스킬 상세는 읽기 전용 PAUSED이며 닫기까지 ticket/revision으로 검사한다. 성장 현황은 설정/선택에서 공격·패시브 목록, 마법 profile, 실제stats/HP를 조회한다. 닫으면 설정 또는 같은 선택으로 돌아가며 네 번째 후보가 아니다. 결과/대기에서는 최종 구성 스냅샷을 보고 새 출격 때 비운다. 영구저장/성장계승 기능은 아니다.

GAME-006 카드에는 ‘선택 시 변화’를 붙였다. 공격9종의 기본피해·간격·발사수/타격상한/연쇄수/반경, 패시브8종의 적용 능력치, 마법 강화 전후를 표시한다. 미보유 공격은 ‘미보유’, 변하지 않는 것은 ‘유지’다. 피해는 공격력/치명타 적용 전 기본값이며 총 적중을 가정한 총피해를 만들지 않는다. vitality는 선택 직후HP, haste는 소총간격과 고유 마법쿨다운 유지, 최초 마법강화는50→65/230→248·MP40/쿨다운12 유지다.

미리보기는 보유레벨 복사본의 순수 조회만 하며 실제 전투와 stats_profile/attack_profile/selection_health를 공유한다. HP/MP·시간·ticket·RNG를 소비하지 않고 확정은 기존 select_skill 경로다. 실제 긴 카드 가독성은 별도 미검증이다.
