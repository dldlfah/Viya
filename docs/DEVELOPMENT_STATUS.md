## 2. 문서 역할과 운영

README → AGENTS → 제작 스킬 → CURRENT → 본 문서 → PLANNED → GAME_DESIGN_BASELINE/ART_APPROVAL → NEXT 순서로 읽는다. AGENTS/스킬의 과거 체크포인트보다 최신 CURRENT/본 문서/NEXT와 사용자 지시가 우선한다.

CURRENT는 최신 사실과 본 문서 안내, DEVELOPMENT_STATUS는 누적 이력·기능·수치·검증·미완성, PLANNED는 확정/후속/보류 계획, NEXT는 다음 연결된 게임 작업 하나다. 의미 있는 업데이트 뒤 세 현황 문서를 함께 갱신한다. 문서/검사/커밋 개수를 게임 완성도로 세지 않는다. 기존 BREAKERS·원조비사·검문과 승인 원본을 변경하지 않는다.

## 3. 사용자 확정사항과 임시값

모바일 가로 서바이버, 전장 주력1명, 현재 실제 캐릭터 데이터는 비야다. 레벨업 후보는 **공통 공격8 + 캐릭터 공격1 + 공통 패시브8(저항 제외) + 캐릭터 필살기 강화1 = 18종**, 기본적으로 서로 다른 무작위3개 중1개 선택이다. 공통16종은 공유하고 전용2종/액티브 설정은 캐릭터 데이터로 교체한다. 시험용 fixture는 새 플레이 캐릭터가 아니다.

전 스킬명은 **`[임시]`**. 공격/패시브 보유 UI는 두 줄, 고유 액티브는 별도 버튼/PC F다. 마법 자체를19번째 후보로 추가하지 않는다. 요구XP는 `(10+(level-1)×6)×3`, 기본드롭5XP이며 획득량3배가 아니다. 서포터는 공격2칸·패시브2칸 **빈 자리만** 둔다.

동시 장착 공격4/패시브4, 시작 소총Lv.1, 강화상한5, 후보 동일확률, 개별 효과/수치·전장·적·마법 자원·연출 시간은 임시다. 후보8종을 장착8칸으로 해석하지 않는다. 비야 ART-001 시안 확정 이후 원화·3D·리깅·코스튬은 보류하며 게임 선행조건이 아니다. 금화 드롭과 클리어 보상은 최신 지시로 추가했다. 수집·뽑기·서포터 효과는 보류다. 금화 사용처는 GAME-014의 계정 공통18종 특성/각3단계까지 연결했고 다른 사용처는 보류다.

### 6.3. 마법·상태반응·실제 결과 표시

`viya_crimson_wave`/[임시] 진홍 파동은 버튼/F→소유자/상태/ticket/MP 검사→기본MP40(계정 감소 적용) 차감→범위피해→기존 처치/XP→HUD다. GAME-011에서 비야의 쿨다운을 제거하고 초당1MP 회복으로 변경했다. 강화0부터 사용하며 강화 선택이 현재 MP를 채우지 않는다. 빈 곳 발동/소비는 임시 정책이다. 이동/마법 손가락은 별개이며 정지·선택·확인·결과·대기에서는 사용/시간이 차단된다.

### 6.4. 모바일·조회·선택 전후 비교

공유배치/compact/안전영역·카드3열 또는1열스크롤·리사이즈 입력해제를 유지한다. 스킬 상세는 읽기 전용 PAUSED이며 닫기까지 ticket/revision으로 검사한다. 성장 현황은 설정/선택에서 공격·패시브 목록, 마법 profile, 실제stats/HP를 조회한다. 닫으면 설정 또는 같은 선택으로 돌아가며 네 번째 후보가 아니다. 결과/대기에서는 최종 구성 스냅샷을 보고 새 출격 때 비운다. 영구저장/성장계승 기능은 아니다.

GAME-006 카드에는 ‘선택 시 변화’를 붙였다. 공격9종의 기본피해·간격·발사수/타격상한/연쇄수/반경, 패시브8종의 적용 능력치, 마법 강화 전후를 표시한다. 미보유 공격은 ‘미보유’, 변하지 않는 것은 ‘유지’다. 피해는 공격력/치명타 적용 전 기본값이며 총 적중을 가정한 총피해를 만들지 않는다. vitality는 선택 직후HP, haste는 소총간격과 고유 마법 마나 소모/회복 유지, 계정 무강화의 최초 마법강화는100→130/460→496·MP40/초당1회복이다. GAME-014 계정의 범위/MP 파생 프로파일은 여기에 추가 적용한다. GAME-006 당시50→65/230→248·쿨다운12는 GAME-011 지시로 대체했다.
