모바일 가로 서바이버, 주력1명, 현재 실제 캐릭터 데이터 비야. 레벨업 후보는 공통공격8+캐릭터공격1+공통패시브8(저항 제외)+캐릭터필살기강화1=18종. 기본적으로 중복 없는 무작위3개 중1개 선택. 공통16종은 공유하고 전용2종/액티브 설정은 캐릭터 데이터로 교체한다. 다른 캐릭터 콘텐츠 완성을 뜻하지 않는다.

공격/패시브 장착 각4, 소총Lv.1 기본장착, 강화상한5, 동일확률, 개별 효과/수치·전장·적·마법 자원·표시 시간은 임시다. 후보8종을 장착8칸으로 해석하지 않는다. 아트·3D·코스튬·수집·경제·서포터 효과를 이번에 확장하지 않았다.

## 6. 기능별 현재 구현

### 전투·한 판 흐름

READY/RUNNING/PAUSED/DEFEAT/CHOOSING/ABANDONED. 출격은 캐릭터 후보/마법 검증 후 위치·HP·통계·적/탄환/픽업/효과·성장/마법/반응을 초기화한다. 알 수 없는 캐릭터를 비야로 조용히 바꾸지 않는다. 이동·경계·적추적·최근접 자동사격·선분 탄환충돌·관통 중복방지·피격무적을 연결했다.

새전투/포기는 확인창을 거치고 취소는 같은 후보/ticket을 보존한다. 확정종료에만 선택을 비운다. 포기는 HP0 패배와 구분한다. 결과는 독립복사이며 대기에서 시간이 흐르지 않는다. 확인 중 포커스상실은 PAUSED 유지, 오래된 메뉴요청은 ticket/revision으로 거절한다.

### 성장과 18종

### 마법·반응·타격 표시

`viya_crimson_wave`/[임시] 진홍 파동: 버튼/F→상태/소유자/ticket/자원검사→한번차감→범위피해→기존처치/XP→HUD. 강화0부터 사용, 강화선택이 MP/쿨다운을 리셋하지 않는다. 빈 곳 소비는 임시정책. 이동/마법 손가락 분리, 정지/선택/확인/결과/대기에서 발동·시간차단.

반응은 종료>피격>마법>레벨업>저체력>기본. 가려진 하위반응은 시간보존, 저체력 별도경고. 문구/테두리 대역이며 최종표정 아트 아님.

CombatCues는 실제HP차감 후 숫자/치명타, 제거후 처치흔적, 수집XP부여후 +XP. 과잉피해 제외, 기존치명타RNG 재사용. 드롭/임의XP부여를 수집성공으로 표시하지 않는다. 수명·개수상한, 전투시간정지, 출격초기화. 초과하면 표시만 버리고 판정/XP는 유지한다. View는 읽기전용이며 무한노드/Timer 생성 없음.

### 모바일·상세·성장 현황
