## 기획·아트 다음 한 단위 — B-03-03 국소 복귀: 눈꺼풀 개구·눈꼬리 영향 검수

입력은 [현재 눈꺼풀/코 선·색 보완본](../tools/higgsfield/requests/plan_b/b03/face_surface_v4/README.md)의 `tools/higgsfield/requests/plan_b/b03/face_surface_v4/viya_face_details.blend`다. 04의 하단 음영/접힌 선·코 표시를 보완하고 코의 안쪽 면 등록·앞머리 혼입을 수정했다. 하지만 시점/조명 가설에서도 원화와의 눈매 인상 차이를 해소했다고 판단하지 못해 **04 전체 원화 인상 미통과·진행**, 다음은03의 **국소 영향 검수**다. 특정 기하 결함을 확정한 상태는 아니다. 전체완료1/8·05/몸·총기·리그 전이다.

현재 색/UV를 유지한 상태에서 **실제 눈꺼풀 개구·눈꼬리와 보이는 눈알 비율**을 원본/현재 투영으로 대조한다. 원본 정면은 주 기준안, 양측면은 깊이/시점 참고다. 원본의 가림·기울기와 수동2D 관찰 불확실성을 구분하고 원본px를 보정된3D 치수나 합격 오차로 강제하지 않는다. 이미 만든 [시점 가설](../tools/higgsfield/requests/plan_b/b03/face_surface_v4/review/view_sensitivity.png)/[조명 비교](../tools/higgsfield/requests/plan_b/b03/face_surface_v4/review/material_sensitivity.png)를 이어 쓰며 같은 전체감사/UV/기술시험을 반복하지 않는다. 가설 각도/재질을 원본 카메라 복원이나 게임 기준으로 채택하지 않는다.

실제로 필요한 경우 해당 눈꺼풀/눈알 부위의 되돌릴 수 있는 국소 제어만 편집한다. 기존4,455정점4,426면·모든 원래 키/R4·코0.55/원본UV·별도UV·현재 눈썹/입선·코 표시/홍채를 보존한다. 평가 형상이 변하면 변위/면 상태와 색·무채색/양 사선·측면, 기존 표면 등록의 영향/필요한 재베이크를 확인한다. 이전R4 전 개구56 고정 수치는 현재에 소급하지 않는다. 03 영향 검수 뒤04 전체 인상을 재확인하고05로 넘어간다.
