## GAME-004D: 실제 타격·처치·경험치 획득의 전투 피드백

기존 GAME-004의 상태→화면 연결을 전장에도 확장하는 다음 구현 단위다. 새로운 전투 규칙이나 정식 이펙트 아트의 승인이 아니다.

1. 현재 코드와 기존 RunState를 재사용한다. Godot가 사용 가능해지면 기존 기반·성장·마법·반응·HUD·내비게이션 시험의 실제 첫 오류를 먼저 고친다. 없는 엔진을 실행한 것으로 보고하거나 검사 기준을 낮추지 않는다.
2. 적이 실제 피해를 받은 경우에만 짧은 피격 강조, 실제 처치에만 소멸 표시, 실제 XP 수집에만 획득 표시를 연결한다. 공격 시도·거절된 중복 입력·드롭 생성 자체를 피해/XP획득 성공으로 표현하지 않는다.
3. 표시 데이터는 개수·수명을 제한하고 RUNNING의 시뮬레이션 시간으로 관리한다. 선택/상세/설정/이탈 확인/결과/대기에서는 정지하고 재출격 시 초기화한다. 대량 적/광역 마법에서 무한 노드·타이머·표시 누적을 만들지 않는다.
4. 표시를 추가해도 피해량·치명타·XP·추첨 RNG·후보/ticket·마법/내비게이션 상태가 달라지지 않도록 분리한다. 전장 View와 mobile_main의 배치·터치 영역을 유지한다. 화면 가림은 임시 도형/색/숫자의 최소 범위로 제한한다.
5. GAME-004C의 확인/취소·포기/패배·대기 복귀를 회귀 대상으로 유지한다. 코드 연결, 실제 정적 검사, 엔진/렌더, 모바일 실기는 각각 구분해 기록한다.
