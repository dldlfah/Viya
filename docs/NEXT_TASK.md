이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

## 기획·아트 다음 한 단위 — B-03-04 얼굴UV·색·선 작업

[03 기본형 자체 검수/현재 파일](../tools/higgsfield/requests/plan_b/b03/head_refinement_v3/README.md)을 이어 쓴다. 입력은 `tools/higgsfield/requests/plan_b/b03/head_refinement_v3/viya_head_rims.blend`다. 03은 기본형 단계 자체 검수를 마쳤고 프로듀서 얼굴 수용/닮음 확정은05에 남아 있다. 전체 B-03은 진행·플랜B 완료1/8이다.

먼저 기존 UV와 눈/입 면 고리를 실제 확인하고 UV checker에서 늘어짐·겹침/이음선·눈/입 영역 배치를 검사한다. 기존 원본4장의 실제 얼굴 픽셀 크기/참조 역할을 확인해 별도 얼굴 재질/UV 영역 등 필요한 최소 작업을 정한다. 정면은 얼굴 인상 주 기준안, 양측면은 깊이/윤곽/시점 대조, 후면은 얼굴 측정 근거가 없다. 원본4장/승인 상태를 유지하고 새 얼굴 원화 생성·유료 업스케일/외부 서비스 대체를 추가하지 않는다.

눈/눈썹·홍채·입선·성숙한 인상과 얼굴색을 기존 형태에 맞춰 배치하고, 정면과 양 사선/측면에서 선 깨짐·이음선·색 뭉침을 확인한다. 전신2K의 작은 얼굴을 그대로 쓰거나4K/8K 확대를 해결로 단정하지 않는다. 정면 이미지를 전체 얼굴에 단순 평면 투영해 측면이 늘어진 상태로 납품하지 않는다. 실제 표시 크기 검수와 원천 색/선·UV 기하 문제를 구분한다.

현재 R3_LidRim/MouthCorner는 각1, 기존 코 R2_NoseSimplify는0.55다. 모든 형태 제어/UV 원본을 보존하며 새UV/재질 변경을 되돌릴 수 있게 분리한다. 현재 면 고리 인덱스/전후602표본은03 패킷에 있다. JSON의 eye_left/right는 정면 작업X 음수/양수 구분으로 원본 helper-l/r 해부학 명칭과 동일하다고 가정하지 않는다. 원본2D좌표는 보정된3D 치수가 아니다.

04에서 색/시점이 형상 결함을 드러내면 해당 부위의03 영향 검수로 복귀한다. 얼굴/완성 외형 프로듀서 판단은05/07, 최종 게임은B-08이며 지금 새 승인을 부여하지 않는다. 얼굴 수용 전 몸/의상/총기·리그로 넘어가지 않는다. 03의 재개방/수치 확인은 눈알 수치 접촉/전체 자기 교차·변형/게임 검증이 아니다. [단계 기준103절/현재109절](PLANNED_WORK.md).
