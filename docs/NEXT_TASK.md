# VIYA — 다음 단일 제작 작업

## 플랜B B-01 — 시범 결과를 바탕으로 정식 조작 확정

제작세션에서 이동 스틱 방향을 조준에 사용하고, 놓으면 방향을 유지하며, 적이 없어도 자동 발사하는 B-02 비교 시범을 실제 전투에서 검증했다. 현재 챕터 완료 수는 **0/8**이다. 프로듀서가 정식 바라보기 입력과 적 부재 발사 정책을 결정하고 검수에 쓸 실제 기종을 정한다. 같은 조작을 시범에서 확인한 근거를 판단에 사용한다. [시범 화면](validation/PLAN_B02_PREVIEW.png) · [인계 규격과 진행표](PLANNED_WORK.md)

기존 Windows 3~5분 전투 측정은 B-02 시범과 비교할 기준이다. 정식 비야 모델과 동작의 제작 경로는 시범 및 실기 근거를 확인해 이어간다. [기획세션 연계문서](PLANNING_SESSION_HANDOFF.md)
