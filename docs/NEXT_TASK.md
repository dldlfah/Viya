## 기획·아트 다음 한 단위 — B-03-04 전체 얼굴 자체 검수

입력은 [현재 눈 표면 보완본](../tools/higgsfield/requests/plan_b/b03/eye_surface_v1/README.md)의 `tools/higgsfield/requests/plan_b/b03/eye_surface_v1/viya_eye_surface.blend`다. 국소R5 형상·모든 키/UV/머리색·홍채를 보존하고 흰자/하단 색만 보완했다. 국소 형상과 색은 검수 작업 기반으로 수용했으나 전체 얼굴은 원화와 인상 차이가 남아 자체 검수 미통과·프로듀서05 전이며 전체완료1/8이다.
