# VIYA — 다음 단일 제작 작업

## 플랜B B-03 — 정식 비야 자산 수령·임포트 확인 대기

**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

## 기획·아트 다음 한 단위 — B-03-04 하단 눈꺼풀 음영/세부선·코 표시 보완

[현재 눈썹/입선 보완본](../tools/higgsfield/requests/plan_b/b03/face_surface_v3/README.md)을 이어 쓴다. 입력은 `tools/higgsfield/requests/plan_b/b03/face_surface_v3/viya_face_expression.blend`다. 눈썹 단일 합성/끝단 테이퍼와 원본 실제 입선/색 국소 전사는 수행했다. 짧은 관찰 눈썹의 직선적인 읽힘/전체 얼굴 인상·하단 눈꺼풀 음영/세부선·코 표시가 달라 **04 자체 검수 미통과·진행**이다. 전체완료1/8이며05/몸·총기·리그로 넘기지 않는다.

다음 한 작업은 **현재UV에 원본 하단 눈꺼풀 음영/세부선과 코의 짧은 그래픽 표시를 국소 보완**하는 것이다. 원본 정면의 실제 범위를 직접 확인하고 관찰값/작성 가정·실제 원천 해상도를 기록한다. 기존 눈/입 면 고리와 코 표면을 사용해 양 사선/측면·무조명/검수 조명에서 선의 연결·번짐과 조명 음영을 구분한다. 원본 전체를 정면 투영하거나 좌우 반전하지 않고 새 디테일 복원으로 주장하지 않는다. 원화의 기울어진 눈 축/입꼬리 높이차를 신체 비대칭이나3D 변위로 복사하지 않는다.

기존4,455정점4,426면·모든 제어/R4·코0.55/평가 제어 좌표·원본UV/별도UV/홍채와 현재 눈썹/입선은 보존한다. UV 재준비/전사 기술 시험·광역 형태 생성부터 되풀이하지 않는다. 원래R4 전 개구56 고정 검증을 현재에 소급하지 않는다. 새 색/선이 실제 형상 결함을 드러내면 해당03 부위만 영향 검수한다. 현재 단일 합성/입선/2D축 관찰은 `feature_registration.json`/`transfer_result.json`, 독립 재개방·원본/모든 제어/UV·패킹 이미지SHA/사선RGBA 동일은 보존 기록에 있다.

검수 셰이더는 무조명65%/Principled35%와 별도 무조명 비교다. 이를 최종Godot 셰이더·눈알 수치 접촉/자기 교차·리그 변형/게임/기기PASS로 확대하지 않는다. [단계 기준103절/최신112절](PLANNED_WORK.md).

새 유료 예산은 없고 승인된 무료 국소 작업을 이어간다. 유료 참조 생성/서비스 업스케일·충전은 하지 않는다. 이번 제출/차감0·잔액 재조회0, 과거3건100/마지막297은 현재 잔액이 아니다. 제작세션은 정식 자산 대기이며 기존 게임/저장 규칙은 유지한다. [현재](CURRENT_WORK.md) · [기획세션 연계](PLANNING_SESSION_HANDOFF.md)
