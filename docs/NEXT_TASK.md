## 다음: 기존 환경설정의 전투 표시 옵션·저장 연결

초기 환경설정 공간과 GAME-004/007 가독성의 후속 구현이다. 새 게임 규칙·아트·스테이지·보스·서포터 효과를 추가하지 않는다.

1. 기존 일시정지/환경설정 화면에 피해 숫자·XP 획득 문구 표시 옵션과 공격 장식 간소화 옵션을 연결한다. 설정 화면·overlay·scroll·safe-area를 재사용한다. 실제 폰트/최소크기는 엔진 확인 가능 범위에서 점검한다.
2. 옵션은 BattleView/표시 helper의 읽기 전용 표시 결정에만 사용한다. 실제 피해·공격 종류/발사수·RNG·처치/XP·마력·쿨다운·반응 시간·보유 스킬·레벨업 후보는 변경하지 않는다. 표시를 꺼도 판정 기록이나 수집을 끊지 않는다.
3. 간소화는 장식선/내부 파동을 줄이는 방식이다. 실제 탄환 위치/진행 방향, 범위의 외곽 경계, 연쇄의 실제 표적 연결과 자동 룬탄/수동 마법 구분을 유지한다. 없는 곳에 판정·타격 성공을 표시하지 않는다.
4. 기존 `user://viya_settings.cfg`의 음량 값을 보존하며 별도 표시 설정 키로 저장한다. 이전 설정 파일, 누락·잘못된 값, 쓰기 실패를 안전하게 처리하고 명시적 기본값을 둔다. 런타임 전투 저장/영구 성장 기능으로 확대하지 않는다.
5. 설정 열기/닫기·레벨업 중 설정 진입·재출격·앱 중단에서 현재 정지/복귀·ticket을 보존한다. 표시 옵션 변경으로 선택지를 다시 추첨하거나 전투가 재개되지 않아야 한다.
6. 기존 시험과 새 옵션/설정 호환 사례를 연결하고 실제 실행한 범위만 기록한다. 이전 자동시험 명령·실패 판정을 삭제/완화하지 않는다. 코드·소스 검사·네이티브·화면·모바일 상태를 구분한다.

완료 기준: 기존 설정 화면에서 표시 변경 → 같은 전투 상태 보존 → 화면 적용 → 설정 저장/다음 실행 복원까지 연결. 프로듀서 검수·자동 엔진·물리기기를 구분해 CURRENT·DEVELOPMENT_STATUS·NEXT를 갱신한다. 비야 아트 보류와 18종/3선택/임시명/요구XP3배를 유지한다.
