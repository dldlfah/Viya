## 기획·아트 다음 한 단위 — B-03-04 R5 눈 개구의 표면톤·홍채 노출 검수

입력은 [현재 국소R5 보완본](../tools/higgsfield/requests/plan_b/b03/eye_refinement_v1/README.md)의 `tools/higgsfield/requests/plan_b/b03/eye_refinement_v1/viya_eye_refinement.blend`다. 기존 색·UV·모든 키를 유지한 R5_LidExpression으로 눈꼬리/위 개구를 보완했고, 기획·아트는 **국소 형상만04 작업 기반으로 수용**했다. 전체 얼굴/원화 닮음은 미통과·프로듀서05 승인 전이며 전체완료1/8이다.

다음 한 작업은 **현재R5를 유지한 흰자·하단 경계톤/홍채 노출의 원본 대비 검수와 필요한 국소 재질 보완**이다. 실제 원본의 보이는 픽셀을 먼저 확인하고 가림/기울기·원천 홍채13×13의 보간 한계·조명을 구분한다. 현재 밝게 보이는 경계가 색/노출 문제인지 실제 형태/가림 문제인지 확인하고 원본을 새 생성/고해상도 복원으로 대체하지 않는다. 필요한 새 맵/등록 설정은 별도 파생물로 만들고 기존PNG/원본4장을 덮어쓰지 않는다.
