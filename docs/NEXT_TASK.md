# VIYA — 다음 단일 제작 작업

## 플랜B B-01 — 제작 수단·조작·인계 규격 확정

현재 완료 **0/8**, B-01은 **진행 중**이다. 제작세션의 Blender→Godot 임포트 시험을 통과했고 인계 규격 초안을 작성했다. 프로듀서가 바라보기 조작과 적 부재 발사 정책을 결정하면 규격에 반영한다. [진행표·담당·완료 기준](PLANNED_WORK.md)의96절과 [세션 역할](PLANNED_WORK.md)의95절을 따른다. 과거Windows 검수NEXT보다 최신 플랜B 진행표를 우선한다.

기획·아트 세션은 실제 사용 가능한 모델링·스키닝/리깅·동작 제작 수단과 연결, 입력/출력·편집 원본·현재 가격을 확인하고 비야 한 모델/한 의상/한 총기의 제작 명세를 준비한다. 과거GLB/잔액/2D 생성 가격을 현재 제작 가능성이나 새 예산으로 가정하지 않는다. 이 단위는 비용 없는 기능·견적 조회/자료 준비이며 단계 등록만으로 유료 제출·결제·충전을 시작하지 않는다.

바라보는 방향의 조작, 정지 시 방향 유지, 적 없는 상태의 발사 정책은 후보와 시범 조건을 정리해 프로듀서가 판단할 수 있게 한다. 제작세션과 좌표/스케일·카메라·뼈대/손·총구 부착점·동작 인계 규격 및 목표 기기/성능 검수 조건을 정한다. 실제 경로·필요한 결정이 남아 있으면 B-01 완료로 보고하지 않는다.

제작세션의 기존Windows Godot3~5분 전투 확인은 B-02 기술 시범 전 비교 기준으로 남긴다. GAME074/GAME076 기준의3:00·3:30·4:00·5:00 프레임 간격/이동 입력을 확인하며 기획·아트의 B-01 자료 준비와 독립 진행할 수 있다. [현재 상태](CURRENT_WORK.md) · [GAME074 계측](validation/GAME074_REPORT.json).

B-01을 실제 완료하면 **“플랜B B-01 완료 — 확인 근거 / 남은 한계 / 다음 B-02”**를 작업 보고에 명시하고 CURRENT/DEVELOPMENT_STATUS/진행표를 갱신한다. 필요한 결정이 남은 자료 준비·생성 성공을 챕터 완료로 세지 않는다.

현재 적용본36클립363프레임과 GAME075·GAME076/모든 원본은 유지한다. 방향 기반 자동사격은 아직 코드에 미반영이고 기존 적 타겟팅이 작동한다. 기존2D 원화 미세 보정/남은 방향 교체를 자동 재개하거나 과거 비리깅/시각 미합격GLB를 승인 모델로 사용하지 않는다. main 자동 병합·force push·유료 Actions는 하지 않는다.
