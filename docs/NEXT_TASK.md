## 플랜B B-03 — 정식 비야 자산 수령·임포트 확인 대기

**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

## 기획·아트 다음 한 단위 — B-03-04 눈썹 연결부·원본 입선 국소 보완

[현재 국소 전사본/검수](../tools/higgsfield/requests/plan_b/b03/face_surface_v2/README.md)을 이어 쓴다. 입력은 `tools/higgsfield/requests/plan_b/b03/face_surface_v2/viya_face_surface_transfer.blend`다. 보이는 원본 눈썹/상단 속눈썹 RGB를 옮겼고 가려진 연장은 작성 가정으로 구분했다. 첫 시험의 빈틈은 줄었지만 관찰/보완 구간의 두께·불투명도가 균일하지 않고 입선/표정도 원화와 달라 **04 자체 검수 미통과·진행**이다. 전체완료1/8이며05/몸·총기·리그로 넘기지 않는다.

다음 한 작업은 **관찰/보완 경계의 눈썹 테이퍼와 원본 입선·색의 국소 표면UV 보완**이다. 현재 입 면 고리와 원본 정면의 실제 입술/입선 범위를 사용하고 정면·양 사선·측면에서 표정/선 연결을 확인한다. 원본 얼굴 전체를 평면 투영하거나 좌우 반전·가려진 부분을 측정값으로 취급하지 않는다. 원본px를 보정된3D 두상 치수로 사용하지 않는다. 입선이 형상 결함을 드러내면 해당03 부위만 영향 검수한다.

기존4,455정점4,426면/모든 형태 제어·R4/코0.55·원본UV/별도UV·양 눈PNG를 유지한다. 이번 전사는 머리색만 바꿨으며 형상 변경0이다. 새UV 준비/같은 전사 기술 시험·광역 형태 생성부터 다시 하지 않는다. 이전R4 도입 전 개구56 고정 수치를 현재에 소급하지 않는다. 실제 원본 경로/가정은 `feature_registration.json`, 전사/영역 밖21px 최대1 재베이크 반올림 복원과 최종 영역 밖0은 `transfer_result.json`, 독립 재개방/이미지SHA·사선RGBA 동일은 보존 기록에 있다.

검수 셰이더는 무조명65%/Principled35%와 별도 무조명 비교다. 원본 실제 얼굴/홍채 해상도 한계와 새 디테일 미복원을 유지하고 최종Godot 셰이더·눈알 수치 접촉/자기 교차·리그 변형/게임/실기PASS로 확대하지 않는다. [단계 기준103절/최신111절](PLANNED_WORK.md).
