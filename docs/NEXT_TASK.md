# VIYA — 다음 단일 게임 작업

## GAME-003: 고유 마법 버튼 → 발동 판정 → 자원·쿨다운 → 레벨업 강화 적용

[PLANNED_WORK.md](PLANNED_WORK.md)와 [CURRENT_WORK.md](CURRENT_WORK.md)를 먼저 읽는다. GAME-002는 코드 연결 및 정적/데이터 검사까지만 완료했고 엔진 동작은 미검증이다. 비야 원화·3D 제작은 보류 유지.

### 범위
1. 같은 브랜치의 실제 코드를 재사용한다. Godot가 확보되면 먼저 `tools/check_project.py --godot ...`로 기반·성장 테스트를 실행하고 실제 첫 오류를 우선 수정한다. 엔진이 없다는 이유로 사용자에게 반복 로그를 요구하지 않는다.
2. 현재 비활성 고유 마법 버튼을 RUNNING 상태에서만 발동 가능하도록 연결한다. 자원·쿨다운·사용 불가 이유·효과·적 피해는 전투 상태가 소유한다. 모든 수치는 임시 표시.
3. `growth.character_id`와 `stats["ultimate"]`의 현재 캐릭터 강화 레벨을 사용한다. 일반 공격 `viya_sigil`과 고유 마법을 혼동하거나 새 필살기 슬롯을 추가하지 않는다.
4. 이동 터치와 마법 버튼의 동시 조작, 반복 입력, 레벨업/설정창/앱 포커스 상실/사망 중 사용 금지, 재시작 초기화를 검증한다.
5. 기존 경험치 18종/3선택, 소유 캐릭터 교체, stale ticket 차단, 최대 적/탄환/픽업, 빈 서포터 2+2를 보존한다.

### 완료 판단
버튼 입력 → 사용 조건 확인 → 자원/쿨다운 1회 차감 → 실제 범위 피해 → 강화 단계 변화 반영 → 표시 갱신을 연결한다. 코드 작성·정적 검사·Godot 실행·모바일 실기를 구분한다. 실행하지 못하면 NOT_VERIFIED를 유지한다. 아트나 수집·서포터·과금으로 범위를 넓히지 않는다.
