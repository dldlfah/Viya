## 플랜B B-03 — 정식 비야 자산 수령·임포트 확인 대기

**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

## 기획·아트 다음 한 단위 — B-03-03 눈꺼풀·코·입 형태 보완 (03 유지)

[원본4장 기준](../tools/higgsfield/requests/plan_b/b03/face_reference_v1/README.md)과 [머리 형태/구조 검수](../tools/higgsfield/requests/plan_b/b03/head_shape_v1/README.md)를 이어 쓴다. 절차적 곡면 모델은 상세 얼굴 구조 부족으로 미채택했으므로 다시 만들거나 기본형으로 쓰지 않는다. 01자료/02국소 시험도 반복하지 않는다.

현재 후속 편집 파일은 `tools/higgsfield/requests/plan_b/b03/head_shape_v1/cc0_topology_trial/cc0_head_topology_study.blend`다. 이는 CC0 해부학 자료에서 머리/목·눈만 구성한 수정용 초안이며 비야의 완성 얼굴이 아니다. 원본UV/정점 인덱스와 되돌릴 수 있는 Shape Key를 유지한다. 출처/사용권·원본 자료는 같은 폴더 source_registry.json을 따른다. 애드온 코드나 전신/의상은 도입하지 않았다.

먼저 원화의 길고 가는 눈꺼풀/눈꼬리와 현재 개구·눈알 접촉을 대조한다. 다음은 더 사실적으로 읽히는 콧대/콧방울·돌출과 입술 볼륨/닫힌 입선을 국소 보완한다. 정면·양측면·사선 무채색을 같은 조건에서 확인하고 원본2D 좌표를 보정된3D 치수/닮음 점수로 쓰지 않는다. 가려진 두상/귀는 관찰과 임시 가정을 구분한다.
