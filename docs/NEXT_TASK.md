## 플랜B B-03 — 정식 비야 자산 수령·임포트 확인 대기

**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

## 기획·아트 다음 한 단위 — B-03-03 눈확·콧방울/입선 형태 조정 (03 유지)

[현재 국소 수정본/검수](../tools/higgsfield/requests/plan_b/b03/head_refinement_v1/README.md)을 이어 쓴다. 후속 편집 원본은 `tools/higgsfield/requests/plan_b/b03/head_refinement_v1/viya_head_refinement.blend`다. 기존 머리 초안과 첫 국소 수정본을 덮어쓰지 않는다. 원본4장 분석/02 편집 경로 시험/미채택 절차적 곡면을 다시 만들지 않는다.

눈꺼풀 개구와 코/입술 돌출을 조정했으나 눈확 주름과 콧방울/비주가 원화보다 사실적으로 남아03 형태 검수는 아직 미통과다. 다음은 기존 면 구조에서 **눈꺼풀 경계와 눈확의 가로 윤곽·바깥 눈꼬리**, **콧방울/비주 밑면과 닫힌 입선**을 국소 조정한다. 정면의 성숙한 인상과 양측면 코/입/턱을 함께 대조하고 반대 시점의 새 돌출/함몰·눈알 틈을 확인한다. 큰 눈 개구만으로 원화 형태가 맞았다고 하지 않는다.

세 부위의 독립 Shape Key와 기존 Basis/비율 제어·UV/토폴로지/원본 정점 인덱스를 유지한다. 새 눈 변위 자료에서 corner1은 바깥, corner2는 안쪽임을 실제 정점으로 확인했다. 파일명으로 반대 역할을 추측하거나 무작위 변위/가짜 형태 점수를 쓰지 않는다. 원본2D 관찰점을 보정된3D 치수로 쓰지 않고 보이지 않는 특징은 가정으로 구분한다.

**03 자체 형태 통과 전04 색칠/전신·리그·유료 생성으로 넘어가지 않는다.** 새 유료 예산은 없다. 현재 저장본의 독립 재개방/원본·UV/제어·렌더 픽셀 보존은 확인됐으나 그것이 닮음·눈알 수치 접촉/자기 교차·리그/게임 검증은 아니다. [단계 기준103절/현재107절](PLANNED_WORK.md).
