# VIYA — 다음 단일 제작 작업

## Windows Godot에서 1스테이지 3~5분 전투 확인

GAME074 최적화와 GAME076 경고 수정이 반영된 작업 브랜치에서 3:00, 3:30, 4:00, 5:00 구간의 프레임 간격과 이동 입력을 확인한다. Linux 계측에서 프레임이 느렸던 3:30과 적이 가장 많이 쌓인 5:00을 우선 비교한다. Windows에서도 끊김이 반복되면 발생 구간의 위치·시야·적 수를 기준으로 재현 장면을 좁힌다.

향후 캐릭터/사격 기획은 [PLANNED_WORK95절](PLANNED_WORK.md)을 따른다. 자동 발사를 유지하고 적 타겟팅 대신 바라보는 방향으로 쏘는 것은 확정된 후속 방향이며 현재 코드에는 미반영이다. 원화풍3D·공통 뼈대·동작 혼합은 추천안, 입력 방식과 적 없는 동안의 발사 정책은 미확정이다. 이번 논의로 위Windows 검수NEXT나 현재36클립363프레임을 교체하거나 모델 제작/유료 생성을 시작하지 않는다.

기획·아트 세션의 후속 준비는 제작 수단 확인과 모델/리그/동작의 제작 명세·검수/납품 기준이다. 제작세션은 현재 검수 뒤3D 표시·방향 기반 사격·동작 연결의 기술 시범을 검토한다. 정식 아트 없이도 임시 리깅 모델/도형으로 기술 조건을 확인할 수 있지만 승인 비야 대체 디자인으로 삼지 않는다. 상세 역할/인계 자료는 같은95절 역할표에 정리했으며 시범 구현/실행은 이번에 하지 않았다.

사용자가 **“비야는 이정도로 하자”**고 현단계 캐릭터 제작을 마감했다. 현재36클립363프레임을 유지하며 비야의 추가 원화/미세 접지 보정/남은 방향 교체나 크레딧 사용을 자동 재개하지 않는다. 잔여 시각 차이는 수용한 한계다. 실기/전투 실행 검수는 계속 별도이며, 미검증 표시를 비야 재제작NEXT로 되돌리는 근거로 삼지 않는다. 다음 아트 논의 후보인 고블린 약탈병1종은 아직 착수하지 않았다.

GAME075는사용자의최신 “적용해”로추가후보03의SW전용이동사격15장을연결했다. 기존35클립348을보존해36클립363이며선택불가/무효메타는같은거리위상SW17로복귀한다. 실제Linuxmain.tscn1,648검사49그리기43발·7네이티브4,740검사PASS다. 최초120초회귀TIMEOUT과별도480초제한전투표현2,469PASS를구분한다. 전환몸/발차이·최종아트/접지와Windows/모바일/FPS는별도검수다. 위Windows단일NEXT를유지한다. 연결추가지출0/제작누적3건89·자동4차없음.
