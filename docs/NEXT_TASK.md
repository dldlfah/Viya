# VIYA — 다음 단일 게임 작업

## GAME-004: 상태 피드백과 한 판 흐름 연결

먼저 [PLANNED_WORK.md](PLANNED_WORK.md), [CURRENT_WORK.md](CURRENT_WORK.md)를 읽는다. 현재 18종/3선택, 스킬명 `[임시]`, 레벨업 요구 XP3배, 고유 마법 코드는 연결했지만 엔진 실행은 미검증이다.

1. 실행 가능한 Godot가 확보되면 먼저 `tools/check_project.py --godot ...`로 기반·성장·마법 테스트를 실제 실행하고 발견한 첫 구문/타입/동작 오류를 수정한다. 미실행을 PASS로 보고하거나 검사를 완화하지 않는다.
2. 전투 상태를 읽는 반응 표시를 연결한다: 기본·피격·레벨업·저체력·마법 발동. 새 비야 원화를 생성하지 말고 임시 초상화 영역/상태 문구·테두리 반응으로 시작한다. 상태 우선순위·복귀 시간을 한 곳에서 관리한다.
3. 출격→이동/공격→처치 경험치→레벨업 선택→고유 마법→피격/사망→결과/재시작의 통합 흐름을 점검한다. 레벨업/설정/앱 중단 시 입력·자원·피드백 타이머가 함께 정지/복귀해야 한다.
4. 새 3배 경험치와 `[임시]` 명칭을 유지한다. 기존 18종 구성, 상태 요청 번호, MP·쿨다운, 적/탄환/픽업 상한, 빈 서포터2+2를 보존한다. 화면의 잘림/마법·이동 동시 입력은 가능한 실제 렌더·기기 환경에서 확인하고 환경별 미검증을 구분한다.

완료 판단은 상태→화면 피드백→복귀와 한 판 재시작이 실제 코드에 연결되는지다. 새 캐릭터·원화·3D·의상·수집·지원 버프·과금은 보류한다. 매번 사용자 PC Pull/로그 제출을 요구하지 않는다. 목표 기기 검증 대기는 검증 실패와 구분한다.
