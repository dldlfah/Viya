## 3:30 전투의 느린 프레임 재현

GAME073과 GAME070 SW17 연결 재검수·보행 보정 이후 이 전투 검증을 재개한다.

가용한 Windows Godot 환경에서 1스테이지를 3분에서 5분까지 실행해 지속 지연과 일시 정지를 확인한다. 3:30의 느린 프레임이 반복되면 같은 전투 상태와 입력에서 적 이동·생성·HUD·렌더 시간을 분리한다. 생성량과 전투 규칙을 유지하면서 재현된 병목부터 보완한다.
