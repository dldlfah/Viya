### 이번 기능 단위
1. 승인된 비야 디자인의 파츠 소유권/좌우 비대칭을 먼저 정의한다: 헤어 앞·뒤 덩어리, 아이보리 탑, 코르셋, 어깨 장갑 L/R, 손목 장갑, 벨트·파우치, 허벅지 스트랩, 검은 하의, 진홍 천 패널 L/R, 장화 L/R.
2. 정면·좌측면·후면·우측면 4장의 동일 부품 위치를 대조하고, **서로 양립하지 않는 위치/형태를 명시**한다.
3. 공통 신체 비율과 어깨/허리/골반/무릎/발목/발바닥 등록선을 정한다. 작화 차이는 숨기거나 비율을 강제로 늘이지 않는다.
4. 수정이 필요한 위치/각도만 별도 보완 원화로 제작·대조한다. 기존 승인 시안과 기존 생성 4장 모두 보존한다. 외부 유료 생성은 잔액/승인 없이 실행하지 않는다.
5. 방향별 부품 대응·접지·실루엣이 프로듀서에게 확인 가능한 자료로 준비되면 `CURRENT_WORK.md`에 **정합화 성립/미성립**을 기록한다.

### 완료 조건
- 최소 신체 기준 + 각 파츠별 4방향 대응표가 실제 PNG에 근거해 작성됨.
- 헤어·진홍색 천·벨트·허벅지 스트랩·부츠 장식의 충돌 영역을 명확히 분류하고, 수정 결과/보류 근거를 남김.
- 독립 3D 베이스 메쉬의 기준이 될 수 있는 수준으로 정리되기 전에는 `model-ready`라고 주장하지 않음.
