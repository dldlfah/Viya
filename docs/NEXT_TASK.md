## 플랜B B-03 — 정식 비야 자산 수령·임포트 확인 대기

**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

기획·아트의 다음은 기존 A포즈 기반 첫 텍스처/자동 리그 후보1개에 대한35크레딧 별도 예산 답변 뒤의 제작이다. 현재는 질문 대기/제출0·실차감0이며 자동 재생성·유료 동작·충전은 포함하지 않는다. 제작세션은 실제 정식 자산을 수령하기 전까지 대기한다. B-02의 완료 판정과 Windows 비교·모바일 실기 검수 상태는 진행표에 남아 있다. [현재 상태](CURRENT_WORK.md) · [기획세션 연계문서](PLANNING_SESSION_HANDOFF.md)
