## GAME-004 통합 마감 — 누적 플레이 경로 오류 수정·첫 실행 검수본 준비

GAME-004의 한 판 흐름/가독성 점검을 마감하는 연결 작업이다. 004E/004F처럼 작은 연출만 계속 추가하는 방향으로 자동 확대하지 않는다. 새 기획·캐릭터·서포터·스테이지·보스·경제·원화는 범위 밖이다.

1. 활성 시작 경로 `project.godot → scenes/main.tscn → mobile_main.gd → main.gd/RunState`를 그대로 사용한다. 기존 코드·데이터·작성된 시험을 확보하고 **전체 파일/데이터 회귀를 다시 실행**한다. 이전 단계의 개별 정적 PASS로 최신 전체 회귀를 대체하지 않는다.
2. 실제 Godot 실행 수단을 확인한다. 사용 가능하면 import/구문·타입 → 기존 기반/성장/마법/반응/HUD/내비게이션/전장피드백 시험 → 실제 시작 장면 순서로 첫 오류부터 수정한다. 기존 시험을 삭제·완화하지 않는다. 확보하지 못하면 미검증을 유지하고 실제 코드 통합 결함 점검·수정을 진행한다. 매번 사용자 PC Pull/로그 요청을 전제하지 않는다.
3. 출격→이동/자동사격→처치/XP→3선택→강화→수동마법→피격/상태/전장표시→이탈 취소/확정 또는 패배→결과→대기/재출격을 **동일 게임 장면**에서 연결해 확인한다. 확인되지 않은 구간은 구체적으로 남긴다.
4. 실제 화면을 얻을 수 있으면 기본/좁은/넓은 가로 화면에서 최소크기·줄바꿈·카드 스크롤·피해 숫자 가림·안전영역·이동/마법 영역을 점검하고 수정한다. 실제 렌더 없이 레이아웃·60FPS 합격을 보고하지 않는다. 합성 입력과 물리 기기 시험을 구분한다.
5. 재시작·선택·상세·설정·이탈 확인·앱 중단의 시간/입력/자원/낡은 요청, 피드백 표시 상한과 전투 RNG 분리를 회귀 대상으로 유지한다. 기존 확정 수치와 아트는 변경하지 않는다.
