# VIYA — 다음 단일 작업

## 작업: 모바일 가로 Godot 전투 기본 루프 시작

### 범위
1. 새로운 Godot 프로젝트에 모바일 가로 화면/기본 해상도 스케일 설정.
2. 임시 비야 플레이어 노드와 가상 터치 이동 조작.
3. 한 종류의 임시 적 생성/추적/피격 및 자동사격.
4. HUD에 HP가 감소하고 적이 제거되는 상태가 연결되도록 구현.

### 완료 조건
- 실제 Godot F5 / 가능한 Android 테스트에서 캐릭터 이동, 적 추적, 자동공격, 피격/체력 갱신이 하나의 장면에서 연결된다.
- 테스트 환경·실제 로그/화면과 코드 SHA를 기록. 실기 미검증이면 NOT_VERIFIED.
- 기존 BREAKERS 프로젝트·원본 비야 디자인 불변.
- 이 단계에서 서포터 버프/수집/스킨/복잡한 스킬 트리는 구현하지 않음.

### 이후
첫 기본 전투 단위가 실제로 동작하면 경험치·레벨업 스킬 선택 단위로 전환한다. 이 이후 단계는 현재 작업이 아니다.
