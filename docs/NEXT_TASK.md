**자산을 업데이트해주세요**

이 중단/수령 기준은 제작세션에 유지한다. 기획·아트가 B-01을 완료해 현재1/8이며 이동 방향 바라보기·정지 뒤 마지막 방향 유지·적 없는 전투 중 자동 발사와 갤럭시S20+를 프로듀서가 확정했다. 실제 도구/견적·아트/기술 인계·검수 조건은 [B-01 패킷](../tools/higgsfield/requests/plan_b/b01/README.md)에 있다. 자료/견적은 정식3D 모델 납품이 아니다.

필요한 것은 승인된 비야 한 모델·한 의상·한 총기의 편집 원본(.blend), 스킨과 공통 뼈대가 포함된 GLB, 재질·텍스처다. 발 원점과 양손·총구 부착점은 인계 규격을 따른다. 수령하면 파일, 리그, 실제 표시 크기, 관절 변형과 총구 부착을 확인한다. [인계 규격](PLANNED_WORK.md#97-플랜b-b-01--제작-경로-시험과-인계-규격-초안-2026-11-28)

## 기획·아트 다음 한 단위 — B-03-04 원본 얼굴 선/색의 국소 표면UV 전사

[현재 얼굴UV/채색 초안·검수](../tools/higgsfield/requests/plan_b/b03/face_surface_v1/README.md)을 이어 쓴다. 입력은 `tools/higgsfield/requests/plan_b/b03/face_surface_v1/viya_face_surface.blend`다. 현재04는 원화의 구체적인 눈썹/상단 속눈썹·입선과 인상 차이가 커서 자체 검수 미통과·진행이다. 05 얼굴 수용/몸·총기/리그로 넘기지 않는다. 전체완료1/8이다.

다음은 원본의 **눈썹·상단 속눈썹 선/색을 국소 표면UV로 옮겨** 현재 단순 곡선 표현을 보완한다. 기존UV/재질·원본UV와 모든 원래 형태 제어·R4를 보존한다. 전체 얼굴을 정면 이미지로 평면 투영하거나 눈/얼굴을 좌우 반전하지 않는다. 정면은 인상 주 기준안이며 양측면은 깊이/시점 대조, 후면은 얼굴 측정 근거가 없다. 가려진 눈썹은 관찰/가정을 구분하고 원본px를 보정된3D 치수로 쓰지 않는다.

현재 색·선 원본/좌표·샘플/실제 해상도는 `surface_authoring.json`, UV/형태 복귀는 `uv_preparation.json`/`shape_feedback.json`에 있다. 홍채 원천13×13px을256 눈UV에 보간했으며 디테일 복원은 하지 않았다. 머리1024/눈 각256의 별도UV·표면 베이크/패킹·재개방은 확인됐으므로 같은 UV 준비/기술 경로 시험부터 다시 하지 않는다. 실제 선/색과 입선 연속성·양 사선/측면을 확인한다.

첫 채색의 둥근 눈은03 국소 복귀로 R4_EyeReadability를 추가해 보완했다. 기존 코0.55와 모든 원래 제어/토폴로지·원본UV는 불변이나 현재 평가 형상은R4로 변했다. 이전03의 개구56 변위0을 지금 상태로 소급하지 않는다. 원래 기본형과 무채색 재질도 보존돼 있다. 새 선/색이 형태 문제를 드러내면 해당03 부위만 영향 검수하고 UV 전체 재배치/광역 형태 수정으로 돌아가지 않는다.

검수용 셰이더는 무조명65%/Principled35% 혼합이다. 원본 선/색 비교에서 조명 효과와 기본 텍스처를 구분하고 최종Godot 셰이더·실기PASS로 세지 않는다. 유한 래스터0겹침은 모든 연속UV의 수학적 무겹침 증명이 아니며, 재개방/이미지해시 확인도 원화 닮음/변형·게임 검증이 아니다. [단계 기준103절/현재110절](PLANNED_WORK.md).

새 유료 예산은 없고 승인된 무료 표면 작업을 이어간다. 새 유료 참조 생성/서비스 업스케일·충전을 붙이지 않는다. 이번 제출/실차감0·잔액 재조회0, 과거3건100/마지막297은 현재 잔액이 아니다. 제작세션은 정식 자산 대기이며 기존 게임은 유지한다. [현재](CURRENT_WORK.md) · [기획세션 연계](PLANNING_SESSION_HANDOFF.md)
