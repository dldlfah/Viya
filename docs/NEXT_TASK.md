# VIYA — 다음 단일 작업

## P0-B: 승인 원본을 기준으로 한 단일 3D 레퍼런스·블로킹 장면

### 변경 이유
앞선 P0에서 동일 부품 대응 계약을 작성하고 실제 보완 원화 R1/R2를 생성했지만 새 소매/다리/장식 등 디자인 변경이 생겼다. 같은 방식의 전체 시트 재생성 반복은 중단한다. 충돌을 해결하는 수단을 하나의 수정 가능한 공통 형상과 정투영 대조로 바꾼다. 최종 모델 제작 승인 또는 원화 정합화 PASS를 의미하지 않는다.

### 반드시 읽을 기준
- `ART_APPROVAL.md`: ART-001만 승인된 캐릭터 디자인 권위.
- `../assets/characters/viya/spec/turnaround_contract.v1.json`: 관측된 14개 파츠 대응·physical 좌우·보존/수정 기준.
- `CURRENT_WORK.md`: R1/R2 미승인. 특히 R2의 새 신체 수치·키·표정 패널을 근거로 사용하지 말 것.

### 이번에 만들 실제 산출물
1. 사용 가능한 Blender 실행/편집 수단을 확인하고, 승인 원본과 기존 네 방향을 수정 없이 배치하는 편집 가능한 레퍼런스 장면을 만든다. 실제 실행 가능한 수단이 없으면 실행한 척하지 말고 재현 가능한 생성 스크립트와 미실행 범위를 구분한다.
2. 정면·후면·좌우 정투영 카메라, 공통 바닥, 신체 높이/어깨/허리/골반/무릎/발목 기준과 **해부학적 L/R** 표기를 연결한다. 현재 네 PNG의 신체 치수를 정확한 정답으로 가정하지 않는다.
3. 승인이 끝난 외형을 참고하는 하나의 저정밀 체형/헤어/의상 볼륨 블로킹을 만든다. 기본 의상은 유지하고, 미확인 뒷면 구조와 헤어 아래 영역은 제안으로 구분한다. 여러 그림을 개별적으로 늘여 겉보기 일치만 만드는 것은 금지한다.
4. 코르셋, 어깨/팔 장갑, 오른쪽 허벅지 스트랩, 왼쪽 연속 레그웨어, 좌우 진홍 천, 장화는 별도 수정 가능한 논리 파츠로 배치한다. 파츠가 나뉘었다고 실제 의상 교체/스키닝이 완성됐다고 보고하지 않는다.
5. 같은 장면에서 나온 정면·옆면·뒷면 검수 렌더와 수정 가능한 원본을 남긴다. 승인 원화와 실제 비교하고 부족한 영역을 명시한다.

### 완료 기준
- 단일 장면/형상에서 네 시점을 실제 생성했거나, 실행 불가 지점과 스크립트가 정직하게 구분되어 있다.
- 기존 PNG, ART-001, R1/R2 결과를 덮어쓰지 않는다.
- 세부 얼굴·헤어 퀄리티, 최종 토폴로지, 리그/애니메이션, 모바일 성능은 아직 별도 검증 대상이다.
- 이번에 Higgsfield 유료 생성/리깅을 임의 호출하지 않는다. 미승인 R1/R2와 SAM GLB를 최종 비야로 쓰지 않는다.

### 후속 대기
블로킹에서 체형·의상 일관성이 성립한 뒤 얼굴/헤어 정교화, 공통 골격과 기본 동작, Godot 모바일 가로 전투로 진행한다. 다른 캐릭터·추가 코스튬·경제 시스템은 여전히 보류한다.
