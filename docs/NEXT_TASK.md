# VIYA — 다음 단일 게임 작업

## GAME-002: 경험치 → 레벨업 선택 → 공격/패시브 표시와 효과 연결

먼저 [통합 작업 예정 문서](PLANNED_WORK.md)와 [현재 상태](CURRENT_WORK.md)를 읽는다. **비야 원화·모델링은 보류이며 이 작업으로 자동 복귀하지 않는다.**

같은 작업 브랜치의 GAME-001 코드를 이어 사용한다. 적 처치에서 경험치가 생성되고 플레이어가 획득하면 레벨업 선택창이 열리도록 연결한다. 최소 공격 강화/패시브 강화 후보를 데이터로 분리하고, 선택 시 실제 피해량 또는 능력치가 바뀌며 두 줄 슬롯의 레벨도 갱신되게 한다. 수집/서포터 버프/과금/새 캐릭터를 끼워 넣지 않는다.

### 완료 조건
- 실제 전투에서 처치 → 경험치 획득 → 선택창 → 효과 반영 → 전투 복귀가 연결된다.
- 선택 중 전투/투사체/피격 타이머가 멈추며, 다중 레벨업·중복 터치·환경설정·사망·재시작과 충돌하지 않는다.
- 현재 적/탄환 상한, 이동 터치 소유권, 재시작 초기화를 보존한다.
- 엔진이 사용 가능하면 먼저 GAME-001의 실제 import/엔진 테스트를 실행해 **발견된 실제 오류를 우선 수정**한 뒤 새 기능을 검증한다. 엔진이 여전히 없으면 미검증을 유지하고 가능한 구현을 진행한다; 매회 사용자 PC 로그 요청이나 서류 검수로 작업을 중단하지 않는다.
- 코드 작성과 Godot 실행 PASS, 모바일 실기 PASS를 구분한다. 최종 실행 미검증은 숨기지 않는다.

이후 마법 연결은 `PLANNED_WORK.md`의 후속 순서를 따른다. 보류 아트 작업에는 별도 재개 지시가 필요하다.
