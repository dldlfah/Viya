## 0. 프로젝트의 경계
- [확정] 신규 **Viya** 프로젝트는 기존 `dldlfah/BREAKERS` 게임 본편과 **독립**된다. 브레이커의 세계관·비야 캐릭터 디자인을 활용하되 기존 프로젝트 코드를 수정하거나 장르를 변경하지 않는다.
- [확정] 주 플랫폼은 **모바일**, 가로 화면. [제안] Android부터 실기 검증, iOS는 별도 후속 검증.
- [합의된 제작 방향] `Godot` 기반; 신규 저장소의 구체적인 엔진 버전·렌더러·화면 기준은 실제 모바일 프로젝트 생성·실측 시 확정한다.

## 1. 핵심 플레이
- [확정] 뱀서류 / 서바이버 액션: 전장에서는 주력 캐릭터 한 명을 직접 조작한다. 적의 물량을 피해 이동하고 자동 공격·스킬 조합으로 성장한다.
- [확정] 비야가 첫 주력 캐릭터다. 현대 화기와 한정된 판타지 마법을 사용한다.
- [합의] 터치 기반 조작을 우선한다. 필살기(마법)는 고유 액티브 스킬로, 전용 버튼 **터치 시 발동**한다.
- [합의] 레벨업 시 스킬 선택. 전투 HUD에 **공격 스킬 1줄 + 패시브 스킬 1줄**의 두 줄 보유 스킬 표시.
- [합의된 UI 형태] 상단 레벨·경험치·전투 진행, 좌측 비야 반응형 초상화와 HP 등 상태, 하단 2줄 스킬 슬롯, 우측 필살기, 환경설정 진입. 스크린샷 시안은 최종 픽셀 규격이 아니다.
- [확정] 초상화는 전투에 반응: 레벨업 시 들뜬 표정 후 복귀, 피격 시 고통, 독 피해 지역 같은 지속 상태이상에서는 괴로운 표정 유지. [제안] 저체력·필살기 표정은 후속 확장.

## 2. 캐릭터 수집과 서포터
- [확정] 주력 **1명** 출전. 수집 캐릭터를 공격 지원 및 패시브 지원으로 활용하는 방향.
- [기본 편성 시안] **공격 지원 슬롯 2개 / 패시브 지원 슬롯 2개**. 초기 구현에서는 **빈 슬롯과 역할만 마련**하고 서포터 AI, 수집, 수치 및 강화는 제작하지 않는다.
- [향후 예시/미확정] 세나: 화염 저항 50%, 두나: '모저' 20%. 수치·효과 정의·중첩 규칙·상한은 **아직 확정하지 않음**.
- [후속 제안] 공격 지원자는 지원 공격과 능력치 보정, 패시브 지원자는 버프 제공. 실제 규칙/동시 편성/캐릭터 중복/획득 방식은 기본 게임 완성 후 설계한다.

## 3. 세계관 기준 (기존 BREAKERS에서 가져오는 확정 요소)
- 멸망 직전의 판타지 세계, 마왕군에 밀린 최후의 도시·연합 방위전.
- 현대 지구 출신 인물들이 전해 준 과학·총기 기술을 현지 재료·마법·공방의 기술로 재구축.
- 총기는 지속 피해의 중심, 마법은 제한되지만 전황을 바꾸는 고가치 수단.
- 비야는 이 세계 출신의 숙련된 성인 여성 전투원, 소총을 사용하고 진홍색 룬 계열 마법을 구사한다.
- 신규 서바이버의 구체적인 세력·캐릭터 등장·스토리·스테이지 목표는 본편 문서의 모든 내용이 자동 확정되는 것이 아니다. 확정/제안을 별도 표시한다.

## 4. 첫 제작 범위: 최소 실제 플레이
이 문서의 목적은 콘텐츠·수치를 처음부터 고정하는 것이 아니라 **모바일에서 실제 동작하는 최초 플레이**를 만드는 데 있다.
1. Godot 모바일 가로 시작 장면, 입력·이동.
2. 임시 비야 플레이어, 적 접근/충돌, 기본 자동사격, HP 피해, 적 제거.
3. 경험치·레벨업, 공격/패시브 선택의 최소 동작.
4. 빈 서포터 슬롯 UI, 환경설정 자리, 클릭형 필살기 자리와 이후 실제 연결.
5. 결과·재시작. 매 시스템은 화면에서 실제 작동해야 완료로 분류한다.

**첫 완료 조건:** 실제 게임 실행 → 주력 이동 → 적 추적·피격·공격 → 경험치·레벨업 선택 → 전투 종료·재시작의 통합 루프가 모바일 대상에서 동작하며, PASS/FAIL/NOT_VERIFIED를 구분하여 기록.

## 6. 2026-11-18 기획 추가 — 캐릭터 성장·활용

본 절은 **기존 기획의 후속 의사결정 요약**이다. 상세한 확정/미확정 구분과 잠정 인원 수치는 [통합 작업 예정 문서 6절](PLANNED_WORK.md#6-캐릭터-수집성급-성장서브-콘텐츠-기획-2026-11-18)에 단일 기준으로 기록한다.

- **[확정: 방향]** 비야는 **기본 지급 D급**, 최종 성장 한도는 **SSS급**, 역할은 **물리 공격형 최상위 주력**이다. 기존 소총·진홍 룬 마법 설정을 유지한다.
- **[확정: 방향]** 등급 계열은 **D·C·B·A·S·SS·SSS**. 각 등급에서 **캐릭터 조각으로 별 5개를 채운 뒤 다음 등급 진화 조건**을 충족한다. 캐릭터별 최대 성장 등급을 둔다.
- **[확정: 방향]** 중복 캐릭터는 전용 조각으로 전환하고, **해당 캐릭터의 최대 등급 5성 달성 뒤 추가 중복은 진화 재료 가루**로 전환한다. 구체 요구 수치와 가루 환산율은 미확정이다.
- **[잠정]** 최종 도달 가능 등급별 전체 후보는 SSS **5명(비야 포함)**, SS 6명, S 8명, A 15명, B 20명, C 30명, D 50명, **합계 134명**. 이는 출시 명단이나 확정 개발량이 아니다.
- **[확정: 방향]** 주력 액션 제작은 **A~SSS급 영웅군**에 집중하고, B~D급은 **일러스트·서포터·탐색·도시 방어 등 비주력 콘텐츠**를 중심으로 한다. D급 출발인 비야는 메인 전투에 처음부터 참가한다. 다른 성장형 영웅의 출전 판정 세부 기준은 미확정이다.
- **[기획 방향/세부 미확정]** 수집 캐릭터를 활용하는 **원정·탐색 및 최후의 도시 방어전**을 검토한다. 시설·생산·호송은 후속 제안이다. 실제 규칙/보상/제작 범위는 결정하지 않았다.
- **[제작 지시 아님]** 이 기획 요약만으로 수집·가챠·134명 캐릭터·서브 콘텐츠를 새 개발 단위로 실행하지 않는다. 현재 GAME-012와 `NEXT_TASK.md`의 구현 순서를 유지한다.
