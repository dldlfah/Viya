- 레벨업은 실제 선택 ticket에 연결한다. 같은 선택창을 설정에서 다시 열었다고 새 반응을 발급하지 않는다. 선택 중에는 시간을 보존하고 선택 이후 전투 시간으로 반응을 마친다.
- `RunState.step()`의 RUNNING 검사 뒤에서만 반응 시간을 갱신한다. 선택·설정·앱 중단·사망에서는 이동·MP·쿨다운·반응이 함께 멈춘다. UI 자체 Timer/Tween이나 실제 시계로 시간을 따로 진행하지 않는다.
