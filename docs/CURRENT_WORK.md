- `scripts/ui/mobile_main.gd`가 기존 main을 상속한다. F5 경로는 `project.godot` → `scenes/main.tscn` → `mobile_main.gd` → 기존 main/상태 소유자다. 두 번째 전투 시뮬레이션을 만들지 않는다.
- `hud_layout.gd` 한곳에서 안전영역, 상단 HUD, 전장, 하단 반응/HP·MP/공격·패시브 두 줄/빈 서포터/마법 버튼 및 모달 사각형을 계산한다.
- 일반 가로 화면은 하단 영역을 가로로 배치한다. 좁은 가로 화면은 반응·HP/MP·마법을 윗부분에, 보유 스킬 두 줄과 지원 빈칸을 아랫부분에 배치하는 compact 분기를 작성했다. 물리 화면 전체가 아니라 실제 논리 UI 크기로 계산한다.
- Android/iOS에서는 `DisplayServer.get_display_safe_area()` 값을 UI 좌표로 변환하고 화면과 교차한 영역을 사용한다. 미지원·빈 값은 전체 뷰포트로 복귀한다. **노치/카메라 홀의 실제 기기 동작은 아직 미검증**이다.
- `move_input.gd`의 고정 좌표 판정을 제거하고 배치에서 받은 이동 영역을 사용한다. 입력 좌표를 컨트롤 로컬로 변환한다. 크기 변경 때 이동·마법 손가락을 해제하고 오래된 마법 요청을 무효화한다. 레벨업 후보나 마력/쿨다운은 재설정하지 않는다.
- 공격/패시브 보유 슬롯은 눌러 **전체 임시 이름·보유 레벨·설명**을 보는 버튼이 됐다. 빈 슬롯은 비활성화한다. 상세창은 기존 전투 상태의 PAUSED를 사용하며 획득/강화/발동 기능은 없다.
- 상세창 닫기는 기존 재개 경로를 사용한다. 선택 상태에서 열었다 닫는 경로도 동일 ticket/후보로 복귀하도록 작성했다. 앱 중단 시 상세창 대신 정지 화면을 유지하고 사용자가 계속하기를 눌러야 한다.
- 레벨업 창은 같은 후보와 콜백을 재사용한다. 넓은 창은 3열, 좁은 창은 1열 스크롤로 표현하며 후보를 삭제하거나 재추첨하지 않는다. 긴 문구는 줄바꿈·스크롤로 읽는다.
- `responsive_feedback_panel.gd`는 기존 반응 표시를 상속해 compact 화면에서 부가 제목·상황 설명만 줄인다. 반응 문구와 별도 저체력 경고는 남긴다. 새 얼굴 그림을 만든 것이 아니다.
