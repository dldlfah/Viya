### 실제 코드 연결

- 기존 무작위 선택 카드에 **‘선택 시 변화’**를 붙였다. 기존 이름/설명·신규/강화·현재→다음 레벨·선택 콜백과 후보 수는 그대로다. 네 번째 후보를 추가하지 않았다.
- 공격9종은 1발 또는 1대상 기본 피해·발동 간격과 해당 공격의 발사 수/탄환당 최대 타격 대상/연쇄 대상/반경을 표시한다. 미보유 공격의 이전 값은 **‘미보유’**이며 존재하지 않는 Lv.0 피해를 만들지 않는다.
- 패시브8종은 실제 적용 능력치의 전후 값을 표시한다. 최대 체력은 최대 HP와 선택 직후 HP를 함께 보여준다. 공격 속도는 소총 간격도 표시하되 **고유 마법 쿨다운이나 현재 남은 공격 대기를 초기화하지 않는다**는 점을 구분한다.
- 필살기 강화는 기존 MagicState.profile의 전후 값을 사용한다. **강화 Lv.0에도 이미 사용 가능한 마법**이므로 최초 강화는 기본 피해50→65, 반경230→248이다. 소모MP40·재사용12초는 ‘유지’로 표시하며 현재 MP와 남은 쿨다운은 건드리지 않는다.
- 공격 피해는 **공격력·치명타 적용 전 기본값**이라고 명시한다. 발사 수나 관통/연쇄 상한을 모든 탄환이 반드시 적중하는 총피해로 표시하지 않는다. 거리·속도는 기존 전투 논리 단위다.
- 기존 mobile_main의 줄바꿈·compact 1열/일반3열·모달 스크롤과 성장 현황 복귀 경로를 재사용한다. 신규 긴 카드의 실제 화면 가독성은 아직 미검증이다.

### 전투와 표시의 계산 일치

`RunState.stats_profile(levels)`, `attack_profile(effect, rank, rate)`, `selection_health(...)`를 순수 조회 함수로 분리하고 **실제 전투/강화와 미리보기가 같은 함수를 사용**하도록 연결했다. 기존 스킬 정의와 유효한 레벨에서의 공식·계수는 유지했다.

새 `scripts/ui/skill_preview.gd`는 실제 보유 레벨의 복사본에서 다음 레벨을 계산한다. 성장 선택·HP/MP·경험치·현재 대기시간·ticket·난수 상태를 바꾸는 API는 호출하지 않는다. 알 수 없는 ID·최대 강화·장착 한도에 걸린 신규 후보는 실제 eligible 기준으로 제외한다. 확정 선택은 기존 `select_skill` 1회 적용 경로를 그대로 사용한다.

기존 RunState 함수30개는 그대로 보존했고 `select_skill`, `_refresh_stats`, `_auto_fire`, `_tick_skills` 4개만 공유 조회 함수로 연결했다. 치명타 난수/피해 확정·이동·드롭·XP·마법 소비·이탈/결과 코드는 변경하지 않았다. main에는 preload와 카드 표시 연결만 추가했다.
