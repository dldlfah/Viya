### 이번 반영

- 비행 공세를 **20→30마리**, 6×5 대형으로 늘렸다. 기존 적 수와 겹치는 위치에 관계없이 확률 이벤트가 발생하면 전부 즉시 생성한다. 지상160마리 한도와 보스 자리를 따로 계산한다. 임시 확률20초마다20%·속도360·수명5초는 유지한다.
- 비행 무리는 직선 경로와 대형을 유지하며 앞을 가로막는 지상 적을 진행 방향으로 밀어낸다. 일반·원거리·고속·고체력·정예·보스에 적용한다. 밀어내기로 HP나 처치 보상을 만들지 않으며 자연 통과는 기존처럼 보상을 주지 않는다. 지상 적은 전장 경계 안에 둔다.
- 비야 필살기의 **기본 피해50→100·반경230→460**, 단계당 증가량도 **피해15→30·반경18→36**으로 올려 전 강화 단계에서2배를 적용했다. 공격력·치명타는 기존 판정을 따른다.
- **재사용 대기시간 제거, 소모 MP40, 초당 MP1 회복**을 적용했다. 최대100MP는 유지한다. 서로 다른 새 입력이면 같은 시점에100→60→20으로 연속 발동하며 같은 요청의 중복 처리는 계속 거절한다. 정지·선택·결과에서는 회복/사용이 멈춘다. 버튼·성장 현황·강화 미리보기도 마나 기준으로 연결했다.

### 저장·기존 기능 보존

저장 버전3은 표준 GAME-009 버전1과 GAME-010 버전2를 변환한다. HP·현재 MP·사용 횟수·스킬/후보·시간·적/탄/수명·난수·금화를 보존하고 **이전 필살기의 남은 대기시간만0**으로 바꾼다. 복원으로 MP를 채우지 않는다. 이미 살아 있는20마리 대형은 그대로 복원하고 새 공세부터30마리를 만든다. 이전 예약 이벤트는 재추첨 없이 즉시 실행한다. 알 수 없는 지문·손상 저장은 자동 초기화하지 않는다.

실제 GAME-009 저장의 HP73·MP48.5·기지급117금화를 보존하고 대기2.75초만 제거했다. GAME-010의27개체/탄/네 난수와 새 버전190개체 저장을 각각 다른 프로세스에서 복원했다. 버튼 연속 사용→백그라운드 중단→프로세스 재실행에서도 MP20과 사용2회가 유지됐다. 밀어내기 도중 저장/복원 후 동일한 입력을 주면 이후 전투 상태가 일치한다.

기본6분·2/4분 저장·5분 보스, 정예1600/보스3200·웨이브2/4/6, 원거리/고속/고체력, 18종·3선택·요구XP3배·기본5XP와 금화 정산을 유지했다. 승인 비야 원화·3D 보류·서포터2+2 빈 슬롯을 보존했다.
