## GAME-004D — 이번에 작성한 게임 기능

- **실제 피격:** `_damage_enemy`가 존재하는 적의 HP를 차감한 뒤에만 적 색 강조와 피해 숫자를 기록한다. 수치 표시는 이론상 피해가 아니라 실제 제거한 HP이며, 남은 HP를 넘는 과잉 피해를 숫자에 더하지 않는다. 기존 피해 계산 자체는 바꾸지 않았다.
- **치명타:** 기존 치명타 판정 결과를 재사용해 색과 `!`로 표시한다. 화면 표시를 위해 난수를 추가로 뽑지 않는다. 짧은 간격의 같은 적 다중 타격은 숫자를 합치며, 그중 하나라도 치명타면 강조된다.
- **실제 처치:** 적 제거와 처치 수 증가 뒤 해당 위치에 짧게 사라지는 원형 흔적을 기록한다. 이미 제거한 ID에 대한 중복 피해 시도는 새 흔적이나 추가 XP를 만들지 않는다.
- **실제 XP 수집:** 픽업을 흡수하고 기존 성장 상태에 XP를 부여한 후에만 `+XP` 표시를 기록한다. 드롭 생성·원거리 픽업·임의 grant_xp 호출 자체는 수집 성공으로 표시하지 않는다. 패시브가 반영된 소수 XP를 저장하며 화면 숫자만 소수 둘째 자리까지 표시한다.
- **레벨업 경계:** XP 수집으로 즉시 CHOOSING이 되더라도 수집 표시를 기록하고 시간을 멈춘다. 선택·상세·설정·이탈 확인·결과·대기에서는 기존 RUNNING 가드에 따라 표시 시간도 멈춘다. 재출격 성공 시 초기화한다.
- `combat_cues.gd`는 표시 전용 RefCounted다. 피해·성장·마력·내비게이션 상태를 소유하지 않는다. 이벤트 최대48개, 피격 강조 최대80개. 넘으면 오래된 **표시만** 제거하며 피해/처치/XP 계산은 막지 않는다.
- `battle_view.gd`의 기존 전장 캔버스가 숫자·색·작은 링을 직접 그린다. 개별 Label/입자 노드·Timer·Tween을 계속 생성하지 않으며 전장 밖은 기존 clip_contents로 제한한다. 새 원화·최종 이펙트·음원은 만들지 않았다.
- 임시 표시 시간: 강조0.12초, 피해 숫자0.50초, 처치 흔적0.35초, XP0.70초. 같은 적 숫자 합산창0.06초, 근접 수집 합산창0.10초. 이 값은 최종 밸런스/연출 승인값이 아니다.
