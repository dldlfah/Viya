기준 커밋 `8f94c65951acf22a76d61197fb145ef108f9866b`의 GAME-001을 이어서 확장했다. `project.godot`, 시작 장면, 이동 입력, 기존 전투 기반 테스트는 바이트 단위로 보존했다.

- `run_state.gd`: 적 사망 → 경험치 드롭 → 접근/흡수 → 레벨업 정지 → 선택 → 능력/공격 반영 → 전투 복귀 경로를 연결했다. 경험치 픽업 상한 초과는 값을 합쳐 보존한다.
- 공통 공격 시제품 8종: 기존 소총, 산탄, 관통탄, 표적 범위 폭발, 주변 범위 타격, 네 방향 발사, 연쇄 타격, 강한 단일탄. 비야 전용 시제품은 진홍 룬 범위 타격이다. 각각 피해 판정 코드에 연결했으나 실제 엔진 실행은 아직 미검증이다.
- 패시브 시제품 8종: 피해량, 자동 공격 빈도, 최대 HP, 이동 속도, 경험치 획득 범위, 획득 경험치, 치명타 확률, 체력 재생. 저항력 계열은 없다.
- `main.gd`: 실제 F5 장면에 경험치 바, 3선택 카드, 신규/강화·레벨 표시, 두 줄 보유 스킬 HUD, 필살기 강화 레벨을 연결했다. 선택 중 이동 입력을 해제하고 전투 타이머를 정지한다.
- 선택 식별번호(ticket)는 재시작 때도 재사용하지 않는다. 이미 처리한 카드, 이전 레벨업·이전 전투의 콜백을 거절한다. 다중 레벨업은 순서대로 처리하며 환경설정 진입/복귀로 후보를 다시 추첨하지 않는다.
- 필살기 강화는 현재 캐릭터별 강화 레벨/상태 저장 및 표시까지만 구현했다. **실제 마법 발동은 GAME-003 미구현**이며 버튼도 비활성 상태와 '발동 연결 예정'을 표시한다.
- 지원 2+2는 빈 자리만 유지한다. 신규 아트·서포터 효과·과금·새 캐릭터 콘텐츠는 제작하지 않았다.

## 시제품 처리값 — 사용자 최종 승인과 구분

18종 구성과 기본 무작위 3선택만 확정 기획이다. 이름·공격 형태·효과 수치·상한은 `prototype=true`로 표시한 구현 시험값이며 UI에도 시제품 표시가 있다.

- 기존 소총 Lv.1을 기본 장착한다. 공격/패시브 각 4칸의 기존 임시 한도를 유지하며 8종을 8칸으로 확대하지 않는다. 비야 전용 공격은 공격 칸을 사용하고 필살기 강화는 별도 영역이다.
- 시험 강화 상한은 데이터의 Lv.5, 유효 후보 동일 확률이다. 최종 밸런스가 아니다.
- 유효 후보가 1~2개이면 남은 후보만 표시한다. 0개이면 '성장 완료 · 계속'으로 추가 보상/새 스킬 없이 복귀하는 임시 예외 처리를 명시했다. 향후 정책 확정과 구분한다.
- 픽업 5 XP, 레벨업 필요 XP 10부터 레벨당 +6, 패시브 계수·공격 주기는 임시 값이다. 수집 배율의 소수 XP를 버리지 않는다.
