### 판정과 분리한 최소 정보

- `_projectile`의 마지막 선택 인자로 `source`를 추가하고 실제 생성한 탄환에만 저장한다. 기존 호출은 기본 소총 표시로 동작한다. 탄환 상한 때문에 생성이 거절되면 기존 탄환의 출처를 덮어쓰지 않는다.
- `_tick_skills`의 산탄/관통/교차/정밀 발사에 기존 effect ID를 전달한다. 연쇄는 실제 `_nearest`가 선택한 표적을 처리하는 도중 **이전 anchor**를 저장하고, 기존 타격 효과에 `from`을 붙인다. 화면에서 새 표적을 찾거나 난수를 뽑지 않는다.
- 연쇄 표적이 처치되어도 당시 연결점은 보존된다. 연쇄의 기존 효과 반경28을 광역 피해 범위처럼 그리지 않는다. 범위 공격의 외곽은 실제 판정 중심/반경을 따르며 장식선은 그 안쪽이다.
- 발사/범위 표시는 공격의 발생이고, 성공 타격·처치·XP는 기존 CombatCues가 실제 결과 뒤에만 표시한다. 빈 방어 사격 범위에 적중 표시를 새로 만들지 않는다.
- 새 `attack_visuals.gd`는 기존 BattleView `_draw` 안에서 쓰는 읽기 전용 helper다. 탄환/효과 배열을 수정하거나 두 번째 시뮬레이션을 만들지 않는다. 새 Node/Timer/Tween/난수는 없다.
- 기존 탄환64·효과32 상한, 수명0.75/0.25초와 수동 마법0.65초, RUNNING 시간 가드·정지/선택/상세/확인/결과/대기·재출격 초기화를 그대로 사용한다. 가독성/FPS의 실측 합격을 뜻하지 않는다.
