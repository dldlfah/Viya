## GAME-054 — 비야 전투 초상화 네 표정 연결 시스템

최신 사용자 요청과 기획서에 따라 전투 초상화 위치에 **전투 기본 / 피격 고통 / HP 아이템 회복·안도 / 레벨업 기쁨**을 연결했다. 네 번째는 기존 기획의 레벨업 반응을 따른다. 코드 **`d3152934278263ca3889a6eba1f5f83f160257c4`**, 트리 `630a4ef5cf32476925ac9cf2110744923b443456`다. 기존 FeedbackState와 단일 RunState를 사용하며 별도 캐릭터/전투 상태를 만들지 않았다.
