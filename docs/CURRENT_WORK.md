### 고유 마법 코드 연결
- `data/prototype_skills.json`의 캐릭터별 `active_magic`으로 액티브 이름·소유자·강화 스킬 ID·수치를 관리한다. 후보 풀에는 추가하지 않으므로 19종이 되지 않는다.
- `scripts/combat/magic_state.gd`가 MP·쿨다운·발동 횟수·단조 증가 요청 번호를 소유한다. `run_state.gd`에서 현재 캐릭터 ID/설정/강화 연결을 검증하고 전투 중에만 자원을 차감한다.
- 버튼 터치/PC 클릭/F → 사용 조건 확인 → MP·쿨다운 1회 차감 → 플레이어 중심 원형 범위 피해 → 기존 적 사망·XP 드롭 경로. 적이 없어도 발동/자원 소모하는 **임시 정책**이다.
- 비야 자동 공격 `viya_sigil`과 별개다. 필살기 강화 `viya_ultimate`의 실제 단계가 액티브 피해·반경에 적용된다. 일반 공격력·치명타는 기존 공통 피해 경로를 따른다.
- 임시 값: 최대 MP100, 소비40, 전투 중 초당5 회복, 쿨다운12초, 기본 피해50·반경230, 강화 단계당 피해+15·반경+18. 단계0부터 사용할 수 있으며 새 스킬 칸을 점유하지 않는다. 밸런스 최종 확정 아님.
- 레벨업 선택/설정/사망/앱 포커스 상실 중 사용을 막고 MP 회복·쿨다운·효과 진행도 멈춘다. 강화 선택은 기존 MP를 채우거나 쿨다운을 초기화하지 않는다.
- 재시작 때 MP·쿨다운·발동 횟수·기존 강화/경험치를 초기화한다. 요청 번호는 재사용하지 않아 이전 전투/정지 이전/이미 처리한 발동 요청을 거절한다.
