- Windows/Android/iOS 기기, 렌더·FPS·발열·안전영역은 **NOT_VERIFIED**.
- 검사 보고: [validation/GAME001_STATIC_REPORT.json](validation/GAME001_STATIC_REPORT.json). 소스별 SHA-256과 소스 묶음 지문을 포함한다.
