## GAME071 — 3분 이후 전투 지연과 캠페인 드롭 개선

적의 벽 우회 계산을 줄이고, 실제 전장의 그림자와 드롭을 공용 텍스처로 그린다. 임시 도형 몬스터는 기존 보행 시계로 그리며 빈 스프라이트 슬롯을 검색하지 않는다. 동일한 게임 상태에서 개체 수, 경로, 이동 거리, 보스·공격·저장 상태 및 난수 스트림을 확인했다.

캠페인 새 출격과 재시작의 금화 드롭률은 30%에서 15%로 조정했다. 진행 중인 전투는 저장된 드롭률로 이어간다. 경험치 지급 규칙, 한 번에 나오는 금화량, 골드 던전 드롭률과 클리어 정산은 기존 규칙을 따른다. 전장에서는 민트색 보석을 더 크게 그리고 금화와 같은 자리에 있을 때도 구분되게 했다.

Godot 4.7.2 Linux X11에서 3:00 프레임 반복 시간 중앙값이 43.19→36.06ms, p95가 57.86→44.61ms였다. 5:00은 중앙값 89.15→72.34ms, p95 115.56→85.40ms였다. 3:30의 p95는 52.51→57.51ms로 늘었다. 동일 시드 자동 플레이에서 3:00의 바닥 금화는 116→62개였고 보석 240개와 처치·성장 진행은 동일했다. [계측·검증 보고서](validation/GAME071_REPORT.json)

Windows PC Godot과 모바일 실기는 미검증이다. GAME070의 남서쪽 보행 원화 작업은 전투 문제를 먼저 다루도록 순서를 조정했다. 현재 활성 비야는 GAME069 35클립·342프레임이며 기존 SW11이 쓰인다. [SW 기준 검수](validation/GAME070_BASELINE_REPORT.json) · [원화 제작 입력](../tools/higgsfield/requests/game070/READY_PACKET.json)

별도 기획 세션에서 SW 패킷과 단일 후보 견적을 확인했으며 기존 보행 프레임을 사용 중이다. [기획 인계](DEVELOPMENT_STATUS.md#877-game070--입력-패키지-실검증과-현재-견적)
