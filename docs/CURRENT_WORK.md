## 최근 게임 코드 — GAME-004B에서 달라진 부분

- 시작 경로: `project.godot` → `scenes/main.tscn` → `scripts/ui/mobile_main.gd` → 기존 `scripts/main.gd` 및 동일 RunState. 두 번째 시뮬레이션은 만들지 않는다.
- `hud_layout.gd`에서 안전영역·상단·전장·이동·하단 상태/스킬/서포터/마법·모달 좌표를 한곳에서 계산한다. 일반/compact 배치를 사용한다.
- `move_input.gd`는 고정 영역 대신 배치가 전달한 이동 영역을 사용하고 좌표를 로컬로 변환한다. 리사이즈 시 이동/마법 소유권 해제·낡은 마법 요청 무효화. XP·후보·MP·쿨다운은 초기화하지 않는다.
- 보유 슬롯 상세는 전체 임시 이름·레벨·효과를 보는 읽기 전용 정지 화면이다. 빈 슬롯 비활성화, 기존 상태 복귀, 앱 중단 시 명시적 계속하기 경로를 작성했다.
- 레벨업 카드는 넓은 창3열/좁은 창1열 스크롤. 후보·ticket·콜백을 재사용하고 재추첨하지 않는다.
- `responsive_feedback_panel.gd`는 기존 반응 패널을 상속해 compact 부가 문구만 줄인다. 새 얼굴 그림을 만들지 않는다.
