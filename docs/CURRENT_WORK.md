### 금화와 스테이지

- 일반 적 처치 드롭은 **10~50**, 정예·보스는 **100~1,000** 금화의 양 끝을 포함한 무작위 정수다. 현재 모든 등급의 드롭 확률 **30%**와 기본 클리어 보상 **100금화**는 임시 조정값이다.
- 처치 시 기존 XP 5와 별도로 금화를 생성한다. 기존 획득 반경으로 흡수하며 HUD에 이번 획득량을 표시한다. 금화 전용 난수를 사용해 기존 전투·선택 난수에 영향을 주지 않는다. 표시 상한에서는 금액을 합쳐 보존한다.
- 기존 무한 전투에 최소 클리어 경로를 연결했다. 임시로 30·60초에 정예가 등장하고, **90초 후 보스를 처치하면 클리어**한다. 90초부터 일반 적 추가 생성을 멈추며 남은 적 전멸은 클리어 조건에 포함하지 않는다. 정예 HP100·보스 HP600은 임시값이다.
- 클리어 시 보스의 마지막 드롭과 바닥 금화를 회수한 뒤 **기본 보상 + 획득 금화**를 결과 화면에 표시하고 누적 보유량에 저장한다. 실패·포기는 지급하지 않는다. 다음 스테이지는 기존 출격 초기화 경로를 사용하며 전투 성장은 새로 시작한다.
- `user://viya_gold.cfg`에 보유량·다음 스테이지·정산 식별자를 함께 저장한다. 중복 결과 열기/재시도는 재지급하지 않는다. 쓰기 실패는 결과 화면에서 재시도하며, 성공 전 다음 출격과 대기 이동을 막는다. 금화 사용처는 보류다.

### 기존 다음 작업을 함께 연결

기존 환경설정의 피해 숫자·XP 획득 문구·공격 장식 간소화 옵션을 연결했다. 실제 탄환·범위 경계·연쇄 끝점·수동 마법 구분은 유지하고 표시만 조정한다. `user://viya_settings.cfg`에 기존 음량과 함께 저장하며 이전 파일·누락/잘못된 값·쓰기를 검증했다. 선택 중 설정을 열어도 같은 후보와 ticket으로 돌아온다.
