# 비야 8방향 캐릭터 파일럿 연결

2026-11-25 (KST), GAME-056. 사용자가 분할 ZIP을 제공한 뒤 **‘기존 전투에 시범 적용’**을 선택해 연결했다. 전장 속 비야의 스프라이트이며, 초상화 원화나 최종 아트 승인으로 취급하지 않는다.

## 실제 적용

[presentation_slots.json](../../data/presentation_slots.json)의 기존 `viya_battle` 하나에 [viya_directional_motion.tres](../../assets/characters/pilot_32/resources/viya_directional_motion.tres)를 지정했다. 기존 53키 중 다른 52경로와 별도 네 초상화 경로는 빈칸이다. 기존 캐릭터·로비·몬스터 슬롯을 늘리지 않았다.

| 상태 | 방향당 프레임 | 원본 FPS / 반복 | 한 주기 |
| --- | --- | --- | --- |
| 대기 `idle` | 1 | 1 / 반복 | 정적 대기 |
| 이동 `run` | 11 | 16.6666666667 / 반복 | 660ms |
| 공격 `attack` | 8 | 50 / 비반복 | 160ms |
| 피격 `hurt` | 6 | 50 / 비반복 | 120ms |

각 상태는 E/SE/S/SW/W/NW/N/NE를 모두 가지며 총 32애니메이션·208프레임이다. GAME056 당시200×248 RGBA 원본을50×62/발 기준 `(0.5,1)`로 연결했다. **GAME058 현재는125×155 기준·전투영역 높이526에 비례하고 원본200×248을 상한으로 표시**한다. 발 기준과 원본 비율/프레임은 유지한다. 자동 좌우 반전·이미지 회전·개별 프레임 재정렬/보간/재도색·재타이밍은 하지 않았다. 이미지가 비야의 이동속도나 사격 주기를 결정하지 않는다.

기존 `ActorMotion`이 이동·실제 발사·피해 이벤트를 관찰하고 `ActorAssets`가 해당 프레임을 선택한다. 우선순위는 피격→공격→이동→대기다. 사선 스테이지에서는 표시 방향을 투영한 뒤 8방향을 선택하고, PNG는 직립 상태로 유지한다. F8 비교 렌더러에도 같은 리소스를 사용한다. 리소스가 없으면 기존 임시 도형으로 돌아간다.

정지·선택은 기존 시뮬레이션 시간과 함께 동결된다. 같은 피격 상태 중 재피격은 표시 종료 시각을 연장하고 원래 프레임 시계는 유지하므로 마지막 프레임을 붙들 수 있다. 복원은 누적 HP/발사 수를 과거 피격·공격 애니메이션으로 재생하지 않는다. 이 계약을 변경하기 위해 게임 코드를 새로 만들지 않았다.

## 출처와 보존

사용자가 제공한 `.z01/.z02/.zip`을 복원하고 ZIP CRC와 395개 체크섬을 확인했다. 원본 패키지는 396파일이다. [출처/전체 런타임 해시](../../assets/characters/pilot_32/source_manifest.json)에 복원 ZIP·리소스·각 PNG의 SHA256을 기록했다.

런타임에는 208 PNG(10,269,848바이트), 원본 그대로의 `.tres`와 208개의 무손실 2D 임포트 설정을 등록했다. PNG는 `frames/`의 이동/공격/피격 200개와 `textures/`의 대기 8개다. 원본 리소스 SHA256은 `11254fff2baec6de74bce61988544a4296a9753007f27bef2950788aea8b6a19`다. 아틀라스24개·masters·검토 GIF와 준비/검증 스크립트는 게임에 복사하거나 실행하지 않았다.

[제공 당시 인계문](../../assets/characters/pilot_32/source_docs/INTEGRATION_HANDOFF_ko.txt)은 원본 출처 기록이다. 그 문서의 ‘게임 미연결/GAME-056 성능 보완 예정’은 납품 당시 상태이며 이번 사용자 선택과 CURRENT/DEVELOPMENT_STATUS가 현재 적용 상태다. 새 이미지 생성이나 033 제작 단위를 자동으로 시작하지 않았다.

## 알려진 아트 한계

제공된 인계문은 NE 이동의 가려진 다리 위상/말미 박자, NE 공격의 무기축·높인 끝자세와 대기의 이음, N↔NE 무기 자세와 NW↔N 천 배치, 일부 W/NW/N 동작의 깊이·박자 차이를 별도 한계로 기록한다. NE 피격 마지막 그림도 대기와 정확히 같은 픽셀/자세를 보증하지 않는다. 이번 연결은 이 그림들을 수정하거나 이음을 완성한 작업이 아니다.

정확한 카메라 각도·완전한 발 접지/가려진 손·장비 결합, 사람의 실시간 가독성·최종 아트 승인은 후속이다. 기존 도형 분기의 머리 깜박임이 PNG에도 자동으로 생긴다고 주장하지 않는다. 기존 피해 표시/방향과 제공된 피격 그림은 각각의 역할을 유지한다.
