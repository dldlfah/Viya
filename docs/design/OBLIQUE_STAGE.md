# 1스테이지 사선 시점과 구조물 높이

2026-11-25 (KST), GAME-055. 비교 기준은 사용자가 다시 제시한 **초기 전투 화면 가이드**다. 후속 전체 배치도는 시설 위치·동선의 기준으로 유지한다. 이번 변경은 시점과 높이 표현이며 정식 아트 승인/제작은 아니다.

## 적용 범위

새 전투와 기존 이어하기의 `siege_battlefield`(1스테이지)에 적용한다. 프롤로그는 별도 구성 대상으로 기존 투영을 유지한다. 외곽·골드 던전과 개발용 F8 평면 렌더러도 기존 경로를 사용한다.

- 세계 좌표를 고정 방위각 **−18도**, 지면 앙각 **55도**로 투영한다. 캐릭터 이동으로 방위각이 돌지 않는다.
- 바닥·구조물·발 위치·탄환·범위 판정/예고는 같은 변환을 사용한다. 배우와 아이템 표식은 직립한 상태로 유지한다.
- 키보드·조이스틱 입력은 화면 방향에서 세계 방향으로 역변환한다. 오른쪽 입력은 화면 오른쪽으로 이동하며, 기존 세계 이동속도와 아날로그 입력 강도·충돌을 보존한다. 같은 키 입력의 세계 방향은 이전 고정축 화면과 달라진다.
- 기존 생성 보호 범위·난수와 저장 호환을 유지하기 위해 기울어진 화면의 네 모서리를 종전 시야 범위 안에 맞춘다. **표시 배율이 올라가 기존보다 가까운 시야가 된다.** 기존 넓이 전체를 같은 배율로 회전한 것이 아니다. 폭과 높이에 따라 필요한 배율을 계산한다.
- 중앙 여유 추적/정지 시 고정 원칙을 유지하고, 사선 변환 후에도 표시 여유가 각 축 화면의 8%를 넘지 않도록 제한한다. 생성용 1.16 범위와 기존 카메라 데이터는 그대로다.

## 구조물 표현

`oblique_scenery.gd`는 기존 충돌 사각형을 지면 발자국으로 사용한다. 그 위에 수직으로 올린 윗면·앞면·측면을 만들고 각 면에 기존 맵 파일럿 텍스처를 연결한다. 원본 PNG는 변경하지 않았다.

성벽의 시각 높이는 기존 표시값의 1.45배, 폐허는 1.35배다. 방책은 기존 높이를 유지한다. 실제 충돌 사각형·장애물 수/시설 위치·통로·파괴 소품/45초 재생성·몬스터 이동과 탄환 차단은 바꾸지 않는다. 측면을 어둡게 하고 상단 테두리·접지 그림자를 더한다. 실제 광원 노드는 만들지 않는다.

배우·소품·장애물은 기울어진 화면의 발 깊이로 정렬한다. 비야를 덮는 구조물은 불투명도 0.28로 낮추고 기존 전경 식별 윤곽을 유지한다. 정예/보스 예고·받은 피해 방향·화면 밖 무리/적탄·레이더의 방향도 같은 투영을 따른다.

## 상태와 성능 경계

기존 단일 RunState와 저장22를 유지한다. 새 투영/캐시는 화면에서 재구성하며 전투 저장·HP·스킬·보상·일곱 난수를 소유하지 않는다. 정지·선택 중 상태와 카메라를 유지하고, 복원은 기존 명시적 Continue를 사용한다. F8은 비교용 렌더러 전환이다.

면 텍스처는 화면 주변의 필요한 조각만 그린다. 투영 행렬은 뷰 하나당 최근 상태 하나를 캐시하고, 새 개체별 노드·동적 조명·타이머는 추가하지 않았다. 이 구현만으로 후반 렉 해소나 모바일 FPS 합격을 주장하지 않는다. GAME052 잔여 부하와 원래 극소 비행수명 저장 경계 문제는 별도 후속이다.
