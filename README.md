저장22는 공개1~21의 원래 맵/배치와 진행·자원·특성·보상/즉시자석과 기존 AI/수치를 보존하며, 새 전투의 끌림 상태/좌표·금액도 저장한다. 구1~15는 패턴0,저장16의0/1·저장17의0/1/2를 그대로 이어가며 신규 캠페인만 패턴3을 사용한다. 기존 망치는 유지하고 주술사의 고정 방향 저주탄을 연결했다. 공격4필드와 실제 탄환을 저장해 소모한 발사/타격을 반복하지 않는다. 구1~10 방어미적용/구11 방어적용·종족/7난수 호환도 유지한다. 기존4인자 `RunState.start`는 레거시 호환용이며 실제 UI는 맵과5번째 규칙 인자를 넘긴다. 실행은 기존 `main.tscn → mobile_main/main → 단일 RunState`다.

새 캠페인은 일반 생성량이 매분 **1→2→4→8→16→32배**로 증가한다. 일반 지상 동시 한도160→320→640과 정예/보스 자리를 확보하고 기존30산개·비행무리는 별도로 유지한다. 정예는 **55/110/170/230초**에 등장한다. 정예 처치 시 임시30% 강화 상자: 현재 보유한 최대Lv.5 미만의 서로 다른1~5종을 각+1하며,가능한 수가 적으면 그 수만 강화한다. 새스킬/XP레벨은 지급하지 않고 실제진화에연결한다. 상자개수/seed와획득제거·강화원장을즉시원자저장/재시도에연결했다. 구1~18의이어하기는생성0,구19의0·1은그대로유지하고새캠페인은2이며골드던전은기존생성/보상을유지한다. 설정은 `data/campaign_encounters.json`이다. 새출격2는화면밖가까운진입/주변부족분보충·먼일반적동일ID재진입을함께쓴다. 첫6초뒤초당최대6보충·분별12/24/48/96/144/192목표이며정예/보스·30무리/비행은재배치하지않는다. 추가설정은 `data/campaign_pressure.json`이다. 구1~19이어하기는기존생성0·1을유지하므로새출격에서개선규칙을확인한다.

두 맵에 상자/항아리/잔해 **각32개**를 자동 공격·스킬로 파괴할 수 있다. 매 파괴20%로1개 아이템: 성공 후HP40%/MP40%/전체 자석10%/보스 제외 제거10%다. 회복은 임시 최대치30%, 자석은 맵 전체XP/금화, 제거는 정예까지 기존 처치 보상·보스 면역이다. **파괴45초 후 재생성**하며 비활성 시간은 멈춘다. 이전 드롭과 새 회차 아이템/남은 시간·독립 난수를 저장한다. 소형 물체는 이동 비충돌이며 기존 성벽·성문 충돌을 유지한다.

총기/활/검/마법 각8종의 임시 스킬 라이브러리와 Lv.1~5 실제 동작/진화를 연결했다. **실제 비야는 총기8+패시브8+자동고유/MP강화2의18후보**만 사용한다. 초기 스탯 잠금에 맞춰 시작은 소총Lv.1만 보유하고 진홍각인탄은 레벨업으로 습득한다.4+4/3선택을 유지한다. 도탄/파편/시차점사·룬 표식·진홍파동Lv5 이중파동을 실제 공격/저장/카드·HUD에 연결했다. 다른24종은 후속캐릭터 라이브러리이며 새캐릭터/마법형 비야를 만들지 않았다. 명칭/수치는임시다.

로비의 **골드 슬라임 던전**에서 별도로3분 전투를 시작할 수 있다. 하루2회/한국시간 자정 초기화·입장 시 차감/이어하기 무료,느린30슬라임 군집·1/2분 저장·보스 없는180초 생존이다. 신규 입장은 처치11~55금화 확정·클리어 시 획득분 전액·실패/포기0이며 캠페인 스테이지는 해금하지 않는다. 이전10회 평균99,271.4는22~110규칙의 기록이며 이번 절반 요청 뒤 평균은 미측정이다. 구저장은 입장 당시 기록된10~50또는22~110규칙과 보유 금화를 유지한다. 초기 입장 상태/사용 횟수와 보상ID를 함께 저장해 중단·중복 지급을 보호한다. 로컬 시계 기준이며 서버 시각/최종 경제/정식 슬라임 아트는 후속이다.

기본 전투 화면은 **고각60도 2.5D 시제품**이다. 반복 바닥/입체벽·발 기준 정렬·비야 가림 완화·고정 HUD를 연결했고,시험 화면의 예약 전투 높이는 안전영역의72.7~74.7%다. 디버그 **F8**로 기존 렌더러와 비교한다. ART-001·GEN-005를 새 스프라이트로 자동 채택하지 않았으며 정식 아트/모바일8~9점 승인은 별도다.

이동 카메라는 **중앙 여유 범위 안에서 고정**된다. 범위를 벗어나면 실제 이동 방향/속도 이내에서만 따라가며,방향 앞서 보기와 정지/반전 뒤 잔여 이동은 제거했다. 임무/선택/정지에서 유지하고Continue에서 추가 중앙 복귀를 하지 않는다. 두 렌더러·좌표 변환/위험 표시는 같은 중심을 쓰고 표시 각 축±8%/고정 생성 시야1.16과 전투·저장/RNG는 유지한다. 실제폰/사용자의 체감 확인은 별도다.

밀집 전투에서는 아군 장식을 자동으로 줄이고 피해 숫자를 실제HP 기준으로 묶어 겹치지 않게 배치한다. 아이템/보스·정예/치명타를 우선하며 적 탄환·조준/접근 경고와 실제 범위 경계는 보존한다. 표시 제한은 실제 피해/적 수/보상을 바꾸지 않는다.

실제 종족별 아트와8방향 idle/run/attack/hurt 프레임 접점을 연결했다. 고정 발pivot·프레임 길이/반복과 시뮬레이션 시간·실제 이동/발사를 사용하며 자동 미러링하지 않는다. 기존40경로/종족13추가 경로는 모두 비어 있고 실제 아트가 없으면 도형으로 복귀한다. 검증용 임시 SpriteFrames는 최종 아트가 아니다.

실제 보스의 화면 밖 방향과 기본 공격 사거리·지형 차단/조준 안내를 HP바 아래 연결했다. 보스 조준은 명중 보장이 아니며 정지/선택/임무·결과/던전에는 남은 안내가 없다. 기존 적 경고·피해 숫자·입력을 보존한다.

실제 잃은HP의 방향·음수숫자/반응 표시와 실제 접촉 가해자의 공격 동작을 연결했다. 탄환 발사자를 추정하지 않고,방어/무적/지형에 막힌 무피해를 타격으로 표시하지 않는다. 같은 단계 회복으로 가려진 피격도 반영하며 정지/새전투/복원은 과거 타격을 재생하지 않는다.

실제 발사·피해/MP·획득/성장·결과에 임시 효과음8종을 연결했다. 공유6플레이어/한번에3종·중요음 우선이며,기존음량/무음/중단·복원에 연결해 과거소리를 재생하지 않는다. 정식음원/음성은 미확정이다.

실제 체크포인트 저장 성공을 기존 임무 버튼에 짧게 안내한다. 로비의 이어하기와 일시정지/임무에서는 저장된 전장·모드·시간/HP·MP·금화/남은 선택을 확인한다. 저장 실패는 기존 정지·재시도를 유지하고,같은 저장/설정/복원에서 가짜 알림을 만들지 않는다.
