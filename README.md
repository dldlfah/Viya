실제 보스 HP·등장 안내·둔화·HP/MP/반응·두 줄 스킬·서포터2+2 빈칸·터치 이동/필살기·안전영역/compact를 연결했다. 빈 `presentation_slots.json`에 나중에 텍스처/프레임·아이콘을 연결한다. 임시 도형은 최종 비야/몬스터 디자인이 아니다.

저장15는 이전1~14의 진행·자원·특성·보상/기존 스킬과 몬스터 스탯·미래 생성도 보존한다. 구1~10의 방어미적용/구11의 방어적용을 유지한다. 신규 출격부터 종족 프로필과 별도7번째 난수를 적용하며 구 저장에 새 스탯/고유기/스킬을 소급 지급하지 않는다. 기존4인자 `RunState.start`는 레거시 호환용이며 실제 UI는 맵과5번째 규칙 인자를 넘긴다. 실행은 기존 `main.tscn → mobile_main/main → 단일 RunState`다.

두 맵에 상자/항아리/잔해 **각32개**를 자동 공격·스킬로 파괴할 수 있다. 매 파괴20%로1개 아이템: 성공 후HP40%/MP40%/전체 자석10%/보스 제외 제거10%다. 회복은 임시 최대치30%, 자석은 맵 전체XP/금화, 제거는 정예까지 기존 처치 보상·보스 면역이다. **파괴45초 후 재생성**하며 비활성 시간은 멈춘다. 이전 드롭과 새 회차 아이템/남은 시간·독립 난수를 저장한다. 소형 물체는 이동 비충돌이며 기존 성벽·성문 충돌을 유지한다.

총기/활/검/마법 각8종의 임시 스킬 라이브러리와 Lv.1~5 실제 동작/진화를 연결했다. **실제 비야는 총기8+패시브8+자동고유/MP강화2의18후보**만 사용한다. 초기 스탯 잠금에 맞춰 시작은 소총Lv.1만 보유하고 진홍각인탄은 레벨업으로 습득한다.4+4/3선택을 유지한다. 도탄/파편/시차점사·룬 표식·진홍파동Lv5 이중파동을 실제 공격/저장/카드·HUD에 연결했다. 다른24종은 후속캐릭터 라이브러리이며 새캐릭터/마법형 비야를 만들지 않았다. 명칭/수치는임시다.

비야 초기 HP100/MP100·이동235·소총10/0.30초/520·물리 관통15%와 일반7/정예3/보스2의 HP·이동·접촉 피해를 기획대로 적용했다. 일반은 시간별 HP/지상속도 배율 후 반올림(해골24→34→43·오크40→56→72), 비행속도360고정이다. 프롤로그는 공성파괴자→주술사/선봉장, 외곽은 주술사→기사/지휘관이며 종족 이름·보스HP와 투창/화살 임시 도형을 표시한다. 전용 정예/보스 패턴·실제 서포터 편성은 후속이며 골드 슬라임 던전은 아래 별도 모드다.

로비의 **골드 슬라임 던전**에서 별도로3분 전투를 시작할 수 있다. 하루2회/한국시간 자정 초기화·입장 시 차감/이어하기 무료,느린30슬라임 군집·1/2분 저장·보스 없는180초 생존이다. 신규 입장은 처치22~110금화 확정·실제10회 평균99,271.4금화/클리어 시 획득분 전액·실패/포기0이며 캠페인 스테이지는 해금하지 않는다. 구1~14의 진행 중 전투는 기존10~50과 보유 금화를 유지한다. 초기 입장 상태/사용 횟수와 보상ID를 함께 저장해 중단·중복 지급을 보호한다. 로컬 시계 기준이며 서버 시각/최종 경제/정식 슬라임 아트는 후속이다.

신규 출격은 `combat_pacing.json`의 모드별 요구XP표×기존3배를 사용하며 드롭5XP는 유지한다. Lv5부터 보유 공격 강화1후보를 우선 포함해3선택을 유지하고,기본무기는 사거리 내 보스를 우선 조준한다. 구1~13저장은pacing0의 기존XP/후보/조준·HP/MP를 유지한다. 진화는 플레이어의 강화 선택으로 진행한다.

기본 전투 화면은 **고각60도 2.5D 시제품**이다. 반복 바닥/입체벽·발 기준 정렬·비야 가림 완화·고정 HUD를 연결했고,시험 화면의 예약 전투 높이는 안전영역의72.7~74.7%다. 디버그 **F8**로 기존 렌더러와 비교한다. ART-001·GEN-005를 새 스프라이트로 자동 채택하지 않았으며 정식 아트/모바일8~9점 승인은 별도다.

사용자 가이드에 맞춰 **차콜/황동 전투 HUD·진홍 룬 MP 버튼·두 줄 아이콘/단계·모바일 임무 펼침/복귀**를 연결했다. 상단 시간/공세·금화와 표준 폭의 작은 레이더는 실제 상태만 표시한다. 바닥/벽/몬스터는 교체 가능한 임시 표현이며 가이드 그림은 최종 아트로 승인되지 않았다. ART-001 기준/GEN-005 승인 대기·게임 미연결·3D보류를 유지한다.
