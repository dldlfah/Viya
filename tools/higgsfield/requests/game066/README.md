# GAME066 — 다음 한 방향: SE 달리기

GAME065 E 이동사격 검수 뒤 사용자의 “다음으로” 지시에 따라 인접 SE 한 방향의 제작 자료를 준비했다. **새 SE 원화 생성·게임 적용은 아직 없다.** 현재 SE는 기존11장이고 E 달리기/이동사격은47장씩이다. 프레임 수 차이를 결함으로 단정하거나 모든 방향 재생성을 자동 실행하지 않는다. 먼저 E↔SE 접지·방향 전환을 같은 기준에서 맞춘다.

- [제작 프롬프트](PROMPT_KO.txt), `request_plan.json`: 기획/Higgsfield 세션 인계. 서비스 API 제출 스키마가 아니다.
- [현재 SE 기준 영상](../../../../docs/validation/GAME066_SE_RUN_REFERENCE.mp4): 현재 자산을 중성 회색 위에서 그대로 재생한 참조다. 새 동작·수정 결과·실시간 성능 측정이 아니다.
- 재현: `tools/export_viya_run_reference.gd -- --direction=se --output=res://.local_validation/GAME066_REFERENCE`를 실제 디스플레이에서 실행하고198장의 캡처를60fps로 인코딩한다. 기본 E 실행도 보존했다.

원화는 사용자 지정 기획/Higgsfield 세션에서 제작하며 현재 기능·비용·잔액을 그때 확인한다. 기술 검수를 최종 아트 승인으로 바꾸지 않는다. 원본과 현재 E 파생물/단일RunState/저장22·7난수·전투 수치를 유지한다. SE 달리기 뒤 필요한 SE 이동사격, 이후 대표 적 고블린1종·표시·초상화·한 판 마감을 이어간다.
