GAME066 — 비야 남동쪽(SE) 달리기 한 주기 제작

완료된 GAME064 E 달리기와 GAME065 E 이동사격을 보존하고, 다음 인접 방향인 SE 달리기 한 방향만 보완한다. 이번 납품은 SE 달리기다. SE 이동사격과 다른6방향·고블린·새 정지공격은 후속이며 한꺼번에 생성하지 않는다.

1. 입력과 정체성
현재 활성 리소스는 assets/characters/pilot_32/game065_e_run_fire/viya_game065_frames.tres다. SE 원본 달리기11장과 idle_se를 방향·카메라·총기/비대칭 의상 참조로 삼고, 채택 E47을 전신 보행의 연속성과 접지 품질 기준으로 함께 참조한다. E를 회전/반전해 SE를 만들지 않는다. ART-001 성인 얼굴·긴 짙은 갈색 웨이브·체형·아이보리 상의·검정 코르셋·부분 장갑·황동/금 장식·짧은 하의·허벅지 스트랩·장화·진홍 천·원래 룬 총기를 유지한다. 임의 흰 소매/갑옷/새 장식·체형 변경 금지.

2. 실제 화면 방향
SE는 화면 오른쪽 아래로 약45도 향하는 기존 스프라이트 방향이다. 맵 자체의 사선 회전과 스프라이트 촬영 방향을 혼동하지 않는다. 기존 SE 이미지의 전면/측면 비율, 고각 카메라, 양손 총기 자세를 유지하고 카메라/배경은 고정한다. 캐릭터는 캔버스 안에서 달리며 카메라가 추적하거나 인물이 화면 밖으로 이동하지 않는다.

3. 한 주기
양발의 접지→지지→이탈→회복이 연속적인 한 주기다. 원래 마지막→첫 프레임뿐 아니라 내부 위상과 머리/골반/총의 높이를 함께 검토한다. 발이 튀거나 미끄러지지 않도록 자연스러운 체중 이동·무릎/발목 움직임을 유지한다. 머리카락과 천도 주기 경계에서 이어진다. 전신 연속 이미지를 제작하며 팔다리 절단/조립·프레임별 아핀 변형·핑퐁·끝 복제·가짜 중간 프레임으로 대신하지 않는다. 필요한 프레임 수로 제작하되47장 자체를 목표로 하지 않는다.

4. 크기와 연동
고정 캔버스200×248, 표시69×85.56, 공통 pivot(100,248), 이동235월드/초, stride155(거리 기준659.574468ms 한 주기)를 유지한다. 제공 영상은 현재 SE11장의 명목660ms 시간표를 재생한 기준 영상이며 수정 완료본이 아니다. E와 SE의 phase_origin을 단순히 같은 숫자로 맞추지 말고 같은 교대 접지에 맞는 실제 랜드마크를 보고 제출한다. 프레임별 흑백/알파 bbox를 바닥에 맞춰 흔들리게 정렬하지 않는다. 자연스러운 발 들림은 유지하고 공통 root와 촬영 크기만 고정한다.

5. 납품
전신 RGBA PNG 연속 이미지와 실제 가변 표시시간 CSV, 각 프레임 총열 끝 좌표, 공통 root/캔버스와 위상 원점의 근거를 납품한다. 선택한 서비스가 RGB 영상만 지원하면 원본 영상을 보존하고 알파 추출의 실제 절차/도구와 한 번의 고정 스케일·이동을 기록한다. 흰/회색 테두리·체커보드·외부 그림자·섬광·탄피·탄환·룬 효과·글자·다른 인물은 이미지에 넣지 않는다. 총구 효과는 엔진에서 실제 발사할 때 표시한다.

6. Higgsfield 실행과 검수
기획/Higgsfield 세션이 현재 모델/입력/출력/알파 지원·가격/잔액을 확인하고 지원되는 입력으로 제작한다. 과거 잔액873.25나 모델명을 현재 값으로 가정하지 않는다. 새 결제·자동 충전·범위 밖 대량 생성은 하지 않는다. 실제 모델/설정/입력 해시·작업ID·비용·출력 해시·탈락본과 채택 근거를 기록한다. 원본208장·ARTFIX001·E달리기/E이동사격 파생물을 덮어쓰지 않는다. 새 출력은 별도 파생 폴더로 납품한다.

게임 적용 시 기존32개 나머지 클립/시간/경로를 보존하며 SE run만 교체한다. 고정 크기의 E↔SE 왕복·정지 복귀·이동 중 실제 사격/총구·전후진·일시정지·여러 주기와 마지막→첫 연결을 실제 게임에서 확인한다. 다른 방향의 기존 보행을 바꾸거나 발사 간격·피해·저장·MP·스폰/보상을 바꾸지 않는다. 생성/기술 QA/게임 연결/실기/프로듀서 최종 승인은 구분한다.
