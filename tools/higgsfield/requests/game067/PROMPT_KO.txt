GAME067 — 비야 SE 전용 전신 이동사격 한 주기

GAME066의 SE 달리기18장을 기준으로 남동쪽(SE) 이동사격을 제작한다. 기존 E 달리기/E 이동사격은 보존한다. 원화 제작은 기획/Higgsfield 세션에서 수행하고, 납품 후 제작 세션이 실제 전투의 발사 관측과 연결·검증한다. 이번 요청으로 다른 방향·새 정지공격·몬스터·초상화를 함께 생성하지 않는다.

[참조와 캐릭터]
현재 게임 리소스: assets/characters/pilot_32/game066_se_run/viya_game066_frames.tres
기준 주기: game066_se_run/frames/viya_run_se_000.png~017.png 및 provenance/frame_timing.csv.
깨끗한 SE18 재생 영상: docs/validation/GAME067_SE_RUN_REFERENCE.mp4. 현재 달리기만 재생한 참조이며 새 사격 영상이 아니다.
SE idle/기존 attack_se는 현재 방향과 총기 세부 참고로 사용한다. E 이동사격은 목표 동작 품질만 참고하고 회전·미러링해 SE로 재사용하지 않는다. 서비스의 지원 입력 수와 형식을 확인해 필요한 참조를 선택한다.

동일한 성인 비야의 얼굴·체형·짙은 갈색 웨이브·아이보리 상의·검정 코르셋·부분 장갑·황동/금 장식·짧은 하의·허벅지 스트랩·장화·비대칭 진홍 천·원래 룬 총기·회화적 화풍을 유지한다. 흰 소매/새 갑옷/장비를 추가하거나 비대칭을 뒤집지 않는다. 화면 오른쪽 아래로 향하는 기존 SE의 전면/측면 비율과 고각 카메라를 유지한다.

[전신 동작]
SE로 달리며 같은 SE 방향을 양손 총기로 조준·발사하는 실제 전신 주기다. 두 발의 교대 접지와 회복, 체중 이동, 상체/어깨의 자연스러운 조준 안정과 절제된 반동, 머리/시선·머리카락/천이 연속적이어야 한다. 발/골반과 총의 위치가 순간 이동하거나 총을 얼굴/가슴에 관통시키지 않는다. SE 원본의 각 보행 시점에서 사격을 켜고 꺼도 같은 발/몸 위상으로 이어져야 한다.

기준 SE18은 원본 영상36~53번/24fps의 연속18포즈(원천750ms)를 명목660ms로 재생한다. 게임은 이동235/stride155에 따라659.574468ms 한 주기를 거리로 구동한다. 현재 SE phase_origin은3/11이다. 숫자 자체를 새로운 사격에 무조건 복사하지 말고 실제 교대 접지/회복 랜드마크로 대응 위상을 측정한다. 공통 거리 위상 보존과 물리 접지 일치는 다른 검증이다. 기존 SE↔E의 2D 접지 일치도 역시 골격/지면 원천 정보가 없는 시각 검토이며 최종 아트 승인으로 간주하지 않는다.

프레임 수18 자체를 목표로 하지 않는다. 자연스러운 전체 주기에 필요한 서로 다른 전신 프레임과 정확한 표시시간을 납품한다. 달리기 파일 이름만 바꾸거나 상체/팔다리를 잘라 조립·아핀 변형·가짜 보간·끝 복제/핑퐁으로 새 사격을 대신하지 않는다. 마지막 distinct 프레임과 첫 프레임도 같은 주기의 인접 시점이어야 한다.

[화면·엔진 경계]
캔버스200×248, 표시69×85.56, 공통 pivot(100,248)을 유지한다. 원본의 프레임별 alpha bbox를 지면에 맞춰 재정렬하지 않는다. 새 원화는 하나의 고정 등록 변환으로 처리하고 프레임별 총열 끝 좌표를 따로 측정한다. 사격으로 총 위치가 달라지면 기존 달리기 총구를 복사하지 않는다. 양발/장화와 총열을 자르지 않는다.

섬광·탄환·탄피·룬 발사 효과·환경·그림자·문자·체커보드를 이미지에 굽지 않는다. 실제 탄환/섬광과 발사 간격·피해는 기존 엔진이 소유한다. 한 번의 발사마다 보행을 초기화하거나 게임 속도를 가속하지 않는다. 전신 조준/반동의 재생과 모든 실탄의1:1동기화를 생성 영상만으로 완료했다고 보고하지 않는다.

[실행·납품·검증]
Higgsfield의 현재 지원 모델/영상·이미지 참조 입력/출력·알파/가격·잔액을 조회한 뒤 지원되는 기능으로 제작한다. 과거 모델/잔액815.25를 현재 값으로 가정하지 않는다. 새 결제·자동 충전·범위 밖 대량 생성은 하지 않는다. 실제 입력·작업ID·설정·견적/실차감·원출력 해시와 탈락/채택 이유를 보존한다. RGB 출력이면 원본 영상과 알파 분리의 실제 방법을 별도로 기록한다.

원본208장·ARTFIX001·GAME064/GAME065·GAME066을 덮어쓰지 않고 파생 폴더에 RGBA PNG, 실제 가변 시간 CSV, 프레임별 총구, 공통 root/캔버스·발 위상 원점의 근거를 납품한다. 단순히 생성됐다는 이유로 기술 채택/최종 승인하지 않는다.

게임 적용은 선택적 run_fire_se와 독립 메타데이터를 기존 관측/표시 경로에 연결한다. 현재 구현의 전용 사격 선택은 E뿐이므로 SE 연결 코드는 납품 검증 후 별도로 확장해야 한다. 클립/메타데이터가 없거나 무효이면 기존 SE 달리기로 같은 위상에서 복귀하고 다른 방향/idle로 잘못 떨어지지 않아야 한다. 실제 발사 켜기/끄기·즉시 명중/벽 소비·E↔SE·후진·정지 공격·피격 우선·일시정지·원래 크기/총구를 생산 main.tscn에서 확인한다.
