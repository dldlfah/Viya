# GAME069 입력 결정

실제 S 정지공격8장과 현재S17/대기를 직접 확인했다. 정지공격이라는 파일명과 달리8장 모두 허리 높이의 대각선 휴대 자세이며 어깨 견착·S정면 조준의 완성 참조는 없다. 이를 올바른 조준 자세로 승인하거나 복사하지 않는다.

첫 생성은 낮은 휴대 자세를start_image에 고정하지 않는다. S17의3/11을 정체성·카메라·반대쪽 지지/회복 참조로, 기존attack_s02를 같은 총/손 접촉 구조 참고로만 사용하는image_references 방식이다. 올바른 견착을 이미 확보했다고 주장하지 않는다. 생성 프롬프트는 총구를 화면아래 중앙으로 두고 원래 개머리판을 오른쪽 어깨에 지지하는 새 자세를 명시한다. 첫 결과의 실제 견착/손/총/방향을 우선 판정하며 휴대 달리기의 연장은 반려한다.

S11 재생 영상·느리게 늘린 구동 영상·접촉 시트·E/SE는 제출하지 않았다. 추가 유료 참조 이미지/다른 서비스·팔다리 조립/변형은 사용하지 않는다. 첫 후보에서 정상 S조준 한 주기를 확보할 수 있으면 로컬 구간선택/알파/등록을 먼저 진행한다. 두 번째 생성은 첫 결과의 구체적 결함과 변경 근거가 있을 때만 별도 견적 후 합산60/최대2건 안에서 진행한다.
