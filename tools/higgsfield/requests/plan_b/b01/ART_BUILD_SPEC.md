# 플랜B 비야 — 아트 제작 명세 초안

범위는 비야 한 모델·한 의상·원래 총기 하나와 이동/지속 사격/필살기·기본 반응이다. 이번 문서는 실제 메시/리그/동작 납품이 아니며 모델 생성은 제출하지 않았다.

## 외형과 모델 구조

- 성숙한 성인 얼굴/몸 비율, 긴 짙은 갈색 웨이브, 아이보리 상의·검정 코르셋·부분 장갑/황동, 짧은 하의·허벅지 스트랩·장화, 원래 편의 비대칭 진홍 천과 룬 총기를 유지한다. 새 소매/장비·얼굴/연령/의상 재설계를 하지 않는다.
- 몸·의상/부츠·머리/천과 **총기**를 제작상 구분한다. 코스튬 교체 시스템은 만들지 않으며 구분의 목적은 관절 변형·가림·양손 총기 접촉의 수정이다. 총을 몸/손가락에 융합해 보행마다 휘게 만들지 않는다.
- 편집 가능한 UV/텍스처·원본 메시와 스키닝을 남긴다. 회화풍 색/명암과 소재 대비를 먼저 맞추고 자동 PBR/광택을 최종 화풍으로 채택하지 않는다. 같은 카메라·실제 게임 크기에서 얼굴/머리·총기·진홍 천의 인지가 유지돼야 한다.
- 견적의 목표20,000폴리곤/quad는 첫 후보의 요청 옵션이며 결과 보장이 아니다. 실제 삼각형 수·메시/재질/텍스처·관절 수는 출력 후 측정하고 성능 시범과 함께 판단한다.
- 머리카락/천은 첫 단계에서 소수 뼈의 연속 동작으로 제어할 수 있게 준비하고 전신 실시간 천 물리를 선행 조건으로 삼지 않는다. 발/무릎/고관절·코르셋/어깨·장화의 변형과 관통을 직접 검수한다.

## 원본·공통 뼈대·총기 부착

- 서비스 원출력GLB와SHA-256을 보존한 뒤 Blender 편집 마스터를 별도로 저장한다. 원출력 자체에 .blend/정리된 파츠/좋은 가중치가 포함돼 있다고 가정하지 않는다.
- 제작세션97절 초안: Blender1단위=1m, 위+Z/모델 정면−Y → Godot 위+Y/모델 정면+Z. 발바닥 중앙root·스케일1을 사용한다.1.72m는 기존 시트/시험 기준이며 확정 해부학 치수와 구분한다. 구2026-11-17 QA의 −Z 제안과 혼용하지 않는다.
- root/골반/척추/목·머리/양팔·양다리/발을 제어 가능한 공통 뼈대로 유지한다. 자동 리그 뼈 이름은 실제 구조/변형을 확인한 뒤 기술 규격에 맞춰 매핑하며 단순 이름 치환만으로 호환을 완료하지 않는다.
- hand_r/hand_l 식별, 오른손의 총기 부착, 총기 기준 왼손 지지점과 총구 중심/앞 방향 Muzzle을 기록한다. 총은 강체처럼 유지하고 양손이 총에서 떨어지거나 몸을 관통하지 않게 한다. 기존2D 프레임별 총구 숫자를 복사하지 않는다.
- 무기 좌표와 실제 발사 방향/출발점은 제작세션에서 연결한다. 원화/동작에 총구 섬광·탄환·탄피·문자/배경·그림자를 굽지 않는다.

## 첫 시범 최소 동작

| 동작 | 제작 기준 |
| --- | --- |
| idle | 정지 조준/호흡. 발 위치와 총기 접촉 안정 |
| locomotion | 양발 교대 접지·지지·이탈·회복의 연속 전신 루프. 첫 시범은 이동 방향을 바라보므로 한 전진 주기를 연속 회전해 사용 |
| aim_fire | 어깨/몸통과 연결된 작은 사격 반동/조준 안정. 이동/정지에 혼합하며 보행을 초기화하지 않음 |
| ultimate | 한 필살기의 전신 발동·복귀. 엔진의 실제 발동/중단 정책과 연결 |
| hurt / death | 짧은 피격과 쓰러짐. 피격 우선/종료·일시정지/복원의 기술 조건에 맞춰 연결 |

클립 원본·초 단위 시간/루프·접지 구간·상체 혼합 범위·발동/복귀 이벤트를 기록한다. 특정17/20/47프레임을 목표로 삼지 않는다. 지면 이동과 실제 발사는 게임 상태가 담당하며 root 이동/사격 반동이 이동 속도나 발사 간격을 바꾸지 않게 한다. 끝→첫, 이동↔사격, 정지/방향 변경에서 같은 보행 진행과 총 위치를 확인한다.

독립 조준을 유지한 후퇴/횡이동은 현재 선택한 첫 조작에 포함되지 않는다. 필요할 때 맞는 보행과 입력을 추가할 수 있게 상태/자산을 분리하며, 지금 검증 완료나 필수 추가 동작으로 기록하지 않는다. 리깅 서비스의 총기 달리기 목록은 존재하지만 전용 비야 동작으로 선택/생성/채택하지 않았다.

## 아트 검수와 제작세션 인계

전체/정면·측면·후면의 같은3D 몸체와 고정 고각/69×85.56 비교를 준비한다. 손·총기·머리·천·장화의 외형/부착, 교대 접지·골반 높이·어깨/반동과 끝→첫을 직접 본다. 동일 메시/뼈대 사용만으로 좋은 움직임을 보장하지 않는다.

납품은 원출력/해시·편집 원본·텍스처/출처·GLB·뼈대/스킨·총기/손/총구 부착점·독립 동작·시간/접지/이벤트·비교 자료·모델/입력/설정/작업ID/견적/실차감·채택/탈락 근거다. 원화 후보·기술 납품·게임 연결·실행/실기·프로듀서 최종 승인을 구분한다.

제작세션의 첫 확인 사항은 이동 입력이 바라보기를 정하는지, 입력 해제 뒤 방향이 유지되는지, 적이 없어도 기본 총기가 정상 주기로 발사되는지, 다른 스킬의 목표가 비야의 바라보기를 덮어쓰지 않는지다. 정지/선택/종료의 기존 발사 가드와 실제 탄환·벽/적 충돌·총구 표시·보행 유지도 실제 게임에서 확인한다. 이번 문서는 이 검증을 수행한 결과가 아니다.
