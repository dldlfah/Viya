# 플랜B B-01 — 기획·아트 제작 준비

2026-11-28 KST. 기존 비야의 정식3D 모델을 만든 결과가 아니라 **현재 기능/연결·견적 확인, 참조 복구, 제작 명세와 확정 조작 인계**다. 유료 제출0·실차감0이며 기존36클립363과 게임 코드를 변경하지 않았다.

## 확정한 첫 시범 조작

프로듀서가 채팅의 두 선택 질문에 직접 답했다. **이동 방향을 바라보고, 입력을 놓으면 마지막 방향 유지. 전투 중 적이 없어도 바라보는 방향으로 기본 총기 자동 발사.** 적 자동 조준/몸 회전은 사용하지 않는다. 선택/일시정지/종료 상태의 기존 발사 금지를 해제한다는 뜻은 아니다. 기존 스킬의 개별 유도/도탄/범위 조준도 이번 결정으로 일괄 폐지하지 않는다. [결정 원본 기록](producer_decisions.json).

첫 시범은 이동 방향과 바라보기가 같으므로 전진 보행 한 주기를 각 방향으로 회전해 사용한다. 독립 조준을 유지한 후퇴/횡이동은 이후 확장으로 남기며 지금 별도 보행 자산 제작을 의무화하지 않는다. 이동/바라보기 상태는 코드에서 구분해 향후 조작을 추가할 수 있게 한다.

## 실제 확인한 제작 수단·현재 견적

로컬 Blender4.3.2와 Godot4.7.2 실행 파일의 버전을 확인했다. 제작세션의 기존 Blender→Godot 임포트 시험은 PLANNED_WORK97절을 따르며 이번에 반복하지 않았다. Higgsfield의 현재 모델 스키마/계정 조회와 가격 사전 확인 결과는 [기능·비용 스냅샷](capability_and_cost_snapshot.json)에 보존했다.

| 후보 구성 | 현재 조회 견적 | 이번 실제 제출/차감 |
| --- | ---: | --- |
| Meshy 단일 이미지→텍스처 포함 메시, 자동 리그/동작 없음 |30크레딧|0건/0|
| 같은 메시+자동 리깅, 추가 동작 없음 |35크레딧|0건/0|

현재 조회 계정 잔액은397크레딧이다. 잔액은 플랜B 배정 예산이 아니며 새3D 제작 예산은 아직 승인되지 않았다. 두 호출 모두 `get_cost:true`로 **No job submitted**를 반환했다. 견적용 GEN-001은 최종 생성 입력 승인과 구분하며 첫 유료 요청은 아직 선택/제출하지 않았다.35크레딧은 후보 생성/자동 리그 견적이고 완성 캐릭터·수정·전용 동작·게임 연결의 총비용이 아니다.

추천 경로는 **단일 캐릭터 참조→Meshy 텍스처/리그 후보→Blender에서 구조·비대칭·몸/의상/총기 분리와 리그를 검수/수정→편집 가능한 .blend 마스터/GLB·독립 동작 납품**이다. Meshy의 중립 A포즈·비대칭 강제 금지·리깅 옵션을 확인했기 때문에 우선 후보로 삼았다. 생성 서비스의 출력은 GLB이며 편집용 .blend는 Blender에서 보존한다. 자동 리그나 .blend 저장만으로 승인 원화 일치/좋은 관절 변형/전용 총기 동작이 완성되지 않는다.

SAM 3D는 기존 시각 미합격/비리깅 출력이 있어 현재 캐릭터를 그대로 완성품으로 재사용하지 않는다. Tripo의 현재 지원도 스키마로 확인했지만 유료 비교 생성은 하지 않았다. 서비스 선택 자체는 생산 결과의 합격이 아니다.

## 참조 정리 결과

기존 ART-004 제작 시트를 복구해 시각 확인했고 저장소 명세의SHA-256과 일치했다. 여러 인물/부위가 있는 시트이므로 기본 단일 인물 입력으로 무조건 넣지 않는다. 동일 RGB의 다른 PNG 인코딩도 확인했다. GEN-001 전신 A포즈 원본을 바이트 그대로 다시 확보하고 별도로 보존했으며 총기를 포함하지 않는 파생 이미지임을 확인했다. [원본 위치·해시·승인 수준](reference_audit.json).

ART-001 승인 방향은 유지하지만 기록된 정확한 원본 해시의 파일은 이번 관련 검색에서 찾지 못했다. ART-004/GEN-001/GEN-005를 새 승인 원화로 바꾸지 않는다. 구4방향의 부품/실루엣 불일치는 해결된 자료로 간주하지 않는다. 실제 적용된 게임 비야와 승인 지침을 기준으로 모델의 외형을 비교해야 한다.

## 납품 명세와 남은 조건

[아트 제작 명세](ART_BUILD_SPEC.md)는 모델/총기 분리·원화 일치·공통 리그·최소 동작·편집 원본/GLB와 검수 기준을 정리한다. 기술 축/단위·총구 부착점은 제작세션의 PLANNED_WORK97절 초안을 우선한다.

프로듀서가 첫 모바일 검수 기기를 **갤럭시S20+**로 지정했다. [제작/검수 기준](production_contract.json)에97절의 단위/축·손/총구·최소 동작, 이번 확정 조작, 60Hz/목표60fps와3:00·3:30·4:00·5:00 비교·지속 성능 측정을 정리했다. 논리UI1280×720과 실제 GPU 해상도는 구분한다. 실제 기종 코드/OS·GPU/전력 상태와 실측 결과는 B-07에서 기록한다. 미실행 기기를PASS로 세지 않는다.

B-01의 제작 수단/현재 견적·참조 역할·조작·기술 인계·대상 기기/검수 기준 준비를 마쳤다. 이는 무료 준비 단계의 완료이며 정식 모델/동작 제작이나 모바일 성능의 합격이 아니다. 정식 비야 외형과 가려진 부품의 해석은 B-03의 실제 후보로 검수한다. ART-001의 정확한 원본 미확보는 기록한 한계이며 이를 찾았다고 주장하거나 파생 이미지를 새 승인 원화로 바꾸지 않는다.

제작세션의 B-02 시범은 코드421f984/문서d2a2adf로 이미 존재한다. 그 결과를 보존하며 기술 챕터의 완료 판정/Windows 비교 상태를 유지한다. 최신e0786e9의 지시로 제작세션은 정식 자산 수령 전까지 대기하며 이 패킷만으로 재개하지 않는다. 다음 기획·아트 실행은 별도 예산이 확정되면 준비된 기존 A포즈 기반 후보1건을 제작하는 것이다. 첫 후보35크레딧/1건을 프로듀서에게 제안했으며 답변 전에는 제출하지 않는다. 자동 재생성·유료 동작·추가 참조 생성·충전은 포함하지 않는다.
