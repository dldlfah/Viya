## 반려한 첫 계산과 수정 방법

첫 고리별 변위/깊이 보정은 좁아진 테두리에서 고리 간 이동량 차이가 커져 새 팬 삼각형4개를 뒤집었다. **모델 저장/렌더 전에 거부**했다. `trial01_folded_rim`에 당시 코드/설정·실패 면/정점 좌표·반려 원인을 보존했으며 실패.blend는 없다. 보관 코드는 당시 스냅숏으로 그 폴더에서 직접 실행하지 않는다.

현재는 고리마다 서로 다른 변위를 주지 않고 눈 주변에 연속 공간Z 변위장을 적용했다. 현재 방식은 spatial_support를 사용하며 parameters.json의 radial_weights는 첫 계산의 잔여 기록으로 사용하지 않는다. 위치X/Y와 눈 도움 메시를 움직이지 않으며 앞면/눈 주변 밖으로 부드럽게0이 된다. 현재 제어 팬 삼각형의 새 뒤집힘/0면적·비유한 좌표0이다. CSV는 실제 재개방 평가 좌표의1,236지원 표본을 포함하며, 그중1개가 키 평가의 부동소수점/1e−8작업m 검사 기준 이하가 되어 실제 변위 정점 집계는1,235개다. 두 수치를 혼동하지 않는다. 검사 기준을 완화해 통과시킨 것이 아니다.

개구28정점 중 양쪽 각각23개에서 눈 도움 표면을 정면 광선으로 맞췄다. 이 표본의 전/후 간격 변화는 최대 약1.046mm이고 양쪽 각각5개는 두 시점 모두의 도움 표면 교차를 얻지 못했다. **정확한 접촉/전체 가림·자기 교차를 검증했다는 뜻이 아니다.** 전체 메시 접촉이나 리그 변형PASS로 승격하지 않는다.

## UV·색 보존과04로 돌아가는 기준

활성 머리1024²/눈 각256²의 패킹PNG 바이트는 입력과 같다. 원본4장/기존UV와 모든 원래 제어도 불변이다. `texture_links.json`에 기존PNG 경로/해시를 기록했고 새 재질색 생성/UV 재배치/베이크는 하지 않았다. 새 형상에 붙은 같은UV로 기존 색이 따라 움직이며 현재의 선/색 영향은 직접 렌더에서 대조했다. 현재 파일은 이미지가 패킹돼 외부.blend 의존이 없다.

같은 카메라/재질/색에서 눈꼬리와 둥근 위 개구의 인상이 완화됐다고 기획·아트가 판단했다. 정면·양 사선/양측면·55도와 무채색을 확인했다. 밝은 흰자/하단 경계와 홍채 노출·전체 인상은 아직 원화와 다르거나 판단이 남는다. **국소 형상은04 작업 기반으로 보존하되 전체 얼굴 자체 검수 미통과/05승인 전**이다.

다음 한 작업은 현재R5를 유지한 **04 눈 흰자·하단 경계톤과 홍채 노출의 원본 대비 검수/필요한 국소 재질 보완**이다. 실제 원본의 보이는 픽셀을 먼저 확인하고 원천 홍채13×13 범위/보간의 한계·가림을 유지한다. 이전 원본PNG를 덮어쓰지 않고 새 파생 맵/설정이 필요하면 별도로 만든다. 원본과 현재의 투영/조명을 구분하며 시점 가설을 원본 카메라/게임 기준으로 승격하지 않는다.

만약 표면을 다시 구워야 하면 **현재R5의 실제 평가 메시를 새로 내보내고 지문/래스터를 갱신**한다. 기존R4 표면 위치 캐시를 같은UV라는 이유만으로 재사용하면 안 된다. UV 자체는 그대로 쓰고 unwrap/전체 자료감사/머리 재생성·유료생성을 반복하지 않는다. 실제 결함이 남으면 해당03 영향 검수로만 복귀하며05/몸·총기/리그로 건너뛰지 않는다.
