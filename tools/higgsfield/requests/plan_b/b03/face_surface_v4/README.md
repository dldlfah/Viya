## 현재 파일과 변경 범위

입력은 `../face_surface_v3/viya_face_expression.blend` SHA `9be1757584e658a52296ba21923492e80e40790c74013add584f411e991f4271`다. 이를 덮어쓰지 않고 `viya_face_details.blend`를 만들었다. 4,455정점4,426면·모든 형상 제어/R4·코0.55·평가 제어 좌표/원본UV·별도UV와 원본4장·양 홍채PNG는 그대로다. **이번 형상 변경0**이며 이전R4 전 개구56 고정 수치는 소급하지 않는다.

머리1024²색에서 눈꺼풀/코 표시의 최종10,419px만 바뀌었다. 중간 프리멀티플라이드RGB/알파를2048²에서 합성·축소한 뒤 입력1024²머리색에 합성해 다른 색의 재베이크 반올림을 피했다. 최종 적용 영역 밖/보호된 눈썹·입선·상단 속눈썹 변경0, 눈 각256²PNG는 바이트 동일하다. `textures/feature_overlay.png`는 별도 straight-alpha RGBA 진단 레이어이며 활성 셰이더 텍스처가 아니다. 활성 파일은 머리RGB색과 기존 눈PNG2개다. 원래 머리 재질/이미지들도 로컬 비교용으로 보존해 패킹 이미지 총수가3개뿐이라고 주장하지 않는다. `.gdignore`로 게임 임포트 제외한다.

## 실제 원본에서 옮긴 부분

정면 원본의 양쪽 하단 눈꺼풀과 위 접힌 선을 각각 직접 확인해 수동 경로를 기록했다. 실제 눈 면 고리의 하단 경로 바깥 피부에만 붉은 음영을 배치하고 상단 속눈썹 보호 띠는 유지했다. 접힌 선은 기존 상단 고리의 일부를 위로 옮긴 작성 경로에 RGB/마스크로 전사했다. 등록 폭·높이/농도는 편집 선택이지 보정된3D 두상 치수나 숨은 구조 측정이 아니다. 양 눈은 각 원본 구간을 사용하고 좌우 복사/전체 정면 사진 투영은 하지 않았다.

코는 원본의10×11px·11×11px 구간에서 두 표시만 분리했다. 주변 실제 피부색을 기준으로 알파를 만들고 현재 코 표면에 국소 배치했다. 출력1024²는 원천 디테일1024²를 의미하지 않으며 원본 픽셀의 bilinear 재샘플/마스크 처리다. 원본4장의 바이트와 화풍·비대칭을 유지하고 원본 이미지 자체를 회전/변형하거나 가려진 부분을 복원하지 않았다.

## 실제로 반려·수정한 문제

1. `trial01_hidden_nose_anchor`: XZ 최근접점만 고르니 코 안쪽 표면(Y약−0.078)에 붙어 표시가 거의 보이지 않았다. 작성XZ의0.8mm 작업 반경에서 가장 앞 표면을 선택하고 실제 렌더 메시의 정면−Y 광선 첫 교차와 깊이를 검사하도록 바꿨다. 이전 두 앵커는 첫 교차보다 작업 좌표상 약17.96mm 뒤여서 거부되며 현재 두 점은0.1mm 임계 이내다. 이는 정면 축의 등록 확인이며 모든 카메라/교차·리그 검증이 아니다. 첫 접힌 선 농도0.72도 강하게 읽혀0.52로 낮췄다.
2. `trial02_occluded_crease`: 오른쪽 접힌 선 끝의 작은 검은 점은 입력 구간에 앞머리가 섞인 것이었다. 원본x813 뒤의 가려진 끝을 제외하고 대상 경로도 실제 보이는 부분으로 줄였다. 머리카락을 눈꺼풀로 옮기거나 숨은 접힌 선을 만들어 채우지 않았다.

각 시험의 코드/입력/색PNG·편집 파일/대표 렌더·반려 이유를 보존했다. 보관 시험의 독립 재개방PASS는 부여하지 않았다. 무료 로컬 수정3회와 유료 제출 횟수를 혼동하지 않는다.

## 시점/조명 비교와 남은 판단

동일한 최종 형상/색으로 기본 머리 조명35%/텍스처65%, 진단용15%/85%, 무조명을 비교했다. 별도로 정면roll−5.57도·yaw±12도/같은roll·pitch+8도/같은roll 가설을 렌더했다. 수동2D 눈 축에서 택한 각도와 시험 yaw/pitch는 원본 카메라를 복원한 값이 아니다. 원본에 좌표 보정을 하거나 그림을 정렬/왜곡하지 않았다. `review_sensitivity.py`는 원래 카메라/재질을 복구하고 `.blend`를 저장하지 않는다. 최종 파일은 기존35%/65% 검수 재질을 유지하며15%/85%나 시험 시점을 게임 기준으로 채택하지 않았다.

코의 부드러운 입체 음영은 조명 비중에 따라 줄지만 현재 시험으로 원화의 눈매 인상 차이를 해결했다고 판단하지 못했다. **이 판단은 아트 자체 검수 결과이며 특정 기하 결함의 확정/닮음 점수가 아니다.** 현재4단계 미통과 상태를 유지한다. 다음은 현재 `.blend`/색·UV/홍채를 보존하고03에서 실제 눈꺼풀 개구·눈꼬리/보이는 눈알 비율을 원화·현재 투영과 대조하는 한 작업이다. 원본의 기울기/가림/수동 관찰 불확실성을 분리하고 실제 필요한 국소 제어만 편집한다. 원본px를3D 정답으로 강제하거나 자료 감사/UV준비·광역 재생성·유료생성으로 돌아가지 않는다. 영향 검수 뒤04 색·다시점을 다시 확인하고05/몸·총기/리그로 건너뛰지 않는다.
