## 실제 수정과 원천/작성 구분

기존13×13/반경5.5px 추출은 수동 중심을 정확한 홍채 범위로 취급해 왼쪽 밝은 표본(737,178)을 제외했다. 원본 픽셀을 직접 열어 양쪽의 가시 홍채 영역을 별도 다각형으로 선택했다. `registration.json`에 원본 좌표/중심/축·범위를 기록했다. 이는 그림의 보이는 특징을 옮기기 위한 근사 등록이며 해부학적 중심·보정된 카메라/3D 치수가 아니다.

선택한 원천 픽셀만 선형 보간 가중치에 참여한다. 큰 사각형 전체를 눈알에 붙이지 않았고 반대쪽 눈 복사/미러·원본 이미지 변경·새 그림/AI 복원은 하지 않았다. 다각형 밖의 원천 기여0은 수치적으로 확인했으나 작은 그림의 어두운 경계/반사 구분까지 의미적으로 완벽하다는 증명은 아니다. 원래의 머리·속눈썹/눈썹/코·입선 맵은 그대로다.

가시 영역만으로 전체 홍채를 회수할 수 없어 원천 기여가 없는 가중치는 **입력의 같은 눈 밑색**을 유지했다. 이것은 기존 전사의 잔존/작성 밑색이며 새로 회수한 세부/완전한 홍채 복원으로 기록하지 않는다. 현재 평균 원천 기여는 왼쪽 약43.4%, 오른쪽 약41.1%다. 기존 홍채 구형 표면 범위/반경0.0068작업m와 가장자리 어둡힘 공식은 유지했고 새 기여에만 적용했다. 흰자/홍채 밖은 입력과 바이트 동일하다.

처음 시험한 균일 어두운 미관찰 영역 채움은 평면 맵에서 하단 전사 경계가 어두운 띠로 읽혀 모델 제작 전에 반려했다. `trial01_flat_hidden_fill/`에 당시 코드·설정/맵·보고/미채택 이유를 보존했다. 시험 모델은 만들지 않았다. 현재는 관찰된 색만 덮고 같은 눈 밑색을 유지해 전사 밖을 임의의 단색으로 단정하지 않는다. 보관 코드의 상대경로는 원래 제작 위치 기준의 이력 스냅샷이며 현재 재현은 아래 명령을 쓴다.

## 누락 표본의 실제 가시성

왼쪽 원본(737,178)의 기여는24개 홍채 텍셀에 존재하며 최대 선형 보간 가중치는 약0.775891이다. 기여>0.1인 텍셀만 임시 녹색으로 렌더해 정면1/사선3/반대 사선1개 임계 픽셀에서 보임을 확인했다. 작은 가시성 진단이며 원화 닮음 점수나 반사 전체 크기/세부 복원 수치가 아니다. 임시 진단색/마스크는 모델의 실제 눈 재질로 저장하지 않았다.

실제 전후/무조명에서 왼쪽의 단조로운 홍채에 원래 밝은 세부와 색 변화가 포함됐다. 눈/눈썹·입의 전체 표정과 둥근 입술/턱 인상 차이는 남으며 머리카락 미제작/원본 투영 차이도 비교 한계다. 머리카락은06 후속으로, 없다는 사실 자체를05 차단의 단독 사유로 삼지 않는다.
