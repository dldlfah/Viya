| 제어 | 실제 역할 | 보존 |
| --- | --- | --- |

두 키는 각각0으로 되돌릴 수 있고 저장값은 각각1이다. 원화의 정면/양측면을 직접 대조해 작성한 시험값이며 원본px에서 보정된3D 치수/카메라/비대칭을 얻었다고 하지 않는다. `parameters.json`에 중심/범위·변위와 작성 선택을, `vertex_changes.csv`에 실제 기존/재개방 좌표·두 제어의 요청 변위를 남겼다.

처음 보완은 입술 돌출/턱을 바꿨지만 입선 중앙 아치가 평평하게 남았다. 기존 `face_surface_v3/bake_expression.py`는 원본 선의 호길이를 실제 입술 중간 경로에 맞춰 배치하므로 원본의 중앙 아치가 그대로 재현된다는 보장이 없었다. `trial01_flat_mouth_arc/`에 당시 모델·코드/설정·구조/재개방 보고/대표 렌더·반려 이유를 보존했다. 기술 검증 통과와 시각 채택을 구분한다.

현재는 같은 맵을 바꾸지 않고 입술 제어에 완만한 중앙 상승/입꼬리 하강을 추가했다. 닫힌 입 주변과 이미지가 함께 움직이므로 평면에 새 입선을 덧칠하거나 기존 입선을 이중으로 남기지 않았다. 새 맵·UV 재배치/표면 베이크·옛R4/R5 위치 캐시 사용은 없다.

## 프로듀서가 판단할 부분

국소 입술/턱 보완은 작업본으로 수용했다. 원화보다 부드러운 뺨/피부 음영·눈썹과 전체 눈/입 표정의 차이는 남는다. 원본은 서로 다른 투영의 그림이고 현재 머리카락/몸·의상·귀걸이·총기/리그는 미제작이다. 가려진 홍채는 일부 기존 밑색이며 회수된 새 세부가 아니다. 이를 숨기거나 정확한 원화 재현/전체 얼굴 자체 검수 최종PASS로 기록하지 않는다.

다음 한 작업은 **현재 얼굴 수준을 몸·의상 제작의 얼굴 기준으로 수용할지, 원화에 더 맞춰 수정할지 중간 판단**이다. 이는 같은 무료 수정의 실행 허가를 반복 요청하는 것이 아니라 프로듀서의 시각 판단이다. 수용하면 정확한 파일/해시와 얼굴만의 범위를05에 고정한 뒤06을 진행한다. 수정이면 지정한 큰 차이부터03/04에서 보완한다. 응답 없음/일반적인‘다음’을 얼굴 수용으로 추정하지 않는다. 머리카락은06 후속이므로 없다는 사실을 얼굴 미통과의 단독 사유로 삼지 않는다.

이번 유료 제출/차감0·아트서비스 호출/잔액 재조회0, 새 유료 예산 없음이다. 과거3건100/마지막297은 현재 잔액이 아니다. 원본208/ARTFIX001/GAME064~076/SAVEFIX001·기존2D36클립363/임시3D·게임 코드/전투·저장 규칙은 그대로다. 게임 연결/실행·Windows/S20+실기·프로듀서05/07/B-08 승인은 전이다.
