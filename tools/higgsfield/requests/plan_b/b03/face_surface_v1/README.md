## UV와 색의 제작 방법

원래UV는 원형 그대로 유지하고 `VIYA_face_surface_uv`를 추가했다. 현재 형태를 복제한 임시 제어 메시에서 원래UV의 이음선192개를 확인하고 angle-based unwrap 후 새UV만 원래 메시로 복사했다. 임시 메시를 제거해 최종 제어 메시 수는 그대로다. 양 눈은 별도 타원체 경도/위도UV를 사용하며 뒤쪽에 이음선을 둔다. 정면 이미지를 머리 전체에 평면 투영하지 않았다.

실제 렌더 subdivision의 위치/UV에서 표면색을 구워1024px 머리 텍스처를 만들었다. 최종 래스터 검사는2048² 샘플에서 중복 적중/0면적UV삼각형0이며 유한UV좌표를 확인했다. 이는 유한 래스터 해상도 검사로 모든 연속UV겹침을 수학적으로 증명하는 것은 아니다. 실제 출력은1024²이고 두 배 표면 샘플 후 축소로 선의 앨리어싱을 줄였다. 새 원화 디테일 복원/서비스 업스케일이 아니다. 1024 출력의 작업단위당 텍셀 밀도10/50/90백분위는 약909/1451/2739다. 이 값은3D 작업 좌표 기준이고 원본 그림의px를 실제 신체 치수로 보정한 값이 아니다.

정면 원본의 피부/눈썹/선·입술색을 직접 샘플했다. 눈·입선은 실제 면 고리에 묶인 곡선, 눈썹은 원본을 보며 작성한 테이퍼 곡선으로 표면 채색했다. 이 선은 원화의 픽셀을 그대로 복사한 것이 아니며, 가려진 눈썹 부분은 제작 가정이다. 홍채는 양쪽 원본에서 각각13×13px 범위를 눈UV로 재샘플했다. 원본 이미지는1536×2048이지만 검토한 정면 얼굴 영역은160×125px이므로 눈 텍스처256²가 원천 디테일256²를 의미하지 않는다. 보간은 했고 새 디테일은 복원하지 않았다. 양측면은 깊이/시점 대조, 후면은 얼굴 측정 근거가 없다는 기존 역할을 유지한다.

색 기본값/손으로 선택한 색과 실제 샘플값은 `surface_authoring.json`에 구분한다. 셰이더는 검수용으로 무조명65%/Principled35% 혼합과 별도 무조명 비교를 사용했다. 베이크된 색에 실시간 조명을 굽지 않았다. 이는 Godot 최종 셰이더/실기 성능 검증이 아니다.

## 색에서 드러난 형상 문제와03 복귀

첫 채색에서 눈이 원화보다 둥글고 크게 읽혀 미채택했다. 색으로 덮지 않고 **03 국소 복귀**로 `R4_EyeReadability`를 새 독립 제어로 추가했다. 눈 주변 가로 수축12%·위 눈꺼풀 최대1.8mm 내려감/아래 최대0.3mm 올림·지지영역 완화와 눈알 가로 동반 보정을 사용했다. 수치는 제작 시험값이며 원본px에서 얻은3D 정답이 아니다.

총4,455정점/4,426면을 유지하고 원래 모든 제어/원래UV는 그대로다. R4 추가로 피부2,118정점/최대 약2.363mm, 눈 각72정점/최대 약2.141mm가 달라졌다. 이전03의 개구56정점 고정 수치를 이번 보정본에 소급하지 않는다. 제어 팬 삼각형 새 반전/0면적·비유한 좌표0과 무채색/양 사선·색 시점을 확인했다. 전체 자기 교차/눈알 수치 접촉·리그 변형은 미검증이다.

눈썹을 낮추고 두께/꼬리 테이퍼, 속눈썹/입선 선폭·색을 보완했다. 현재는 과한 둥근 눈 읽힘이 줄었으나 원화의 구체적인 눈썹/상단 속눈썹 묘사와 입선/표현이 아직 다르다. 이 결과를 원화 일치/얼굴 수용으로 세지 않는다. 색/형상을 함께 확인하는 복귀 경로가 실제로 필요했음을 기록한다.

## 다음 한 작업

현재 `.blend`의UV/보정 제어를 이어 쓰며 **원본의 눈썹·상단 속눈썹 선을 국소 표면UV로 옮기는 작업**을 한다. 현재 단순 곡선 표현을 원본 선/색에 더 가깝게 만들고 정면·양 사선/측면과 입선 연속성을 확인한다. 원본의 가려진 부분은 관찰/가정을 구분하고 그림 전체를 정면 투영하거나 좌우 반전하지 않는다. UV 전체 재배치/03 광역 보정/유료 참조 생성으로 되돌아가지 않는다. 선/색이 새 형태 결함을 드러내면 해당03 부위만 재검수한다. 04 자체검수 통과 전05 얼굴 수용/몸·총기·리그로 넘기지 않는다.
