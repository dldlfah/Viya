## 실제 편집과 결과

입력은 이전 `head_refinement_v1/viya_head_refinement.blend`(SHA `80a4c9b43a0acb9f8f865f619d241d61b2efaf50dea209ec9878d2e7266acdf6`)다. 새 머리를 재구성하지 않았다. 기존 모든 Shape Key 좌표/값/상대 기준과UV/면 구조·원래 정점 인덱스를 유지하고 Basis를 상대 기준으로 하는 네 독립 제어를 추가했다.

| 제어 | 현재 값 | 실제 처리 |
| --- | --- | --- |
| R2_EyeContour | 1 | 눈의 가로 윤곽/바깥 눈꼬리와 개구, 양쪽 눈알에 같은 기본 윤곽 변환. 위·아래 눈확은 이웃 정점의 깊이 평균으로 완화 |
| R2_NoseSimplify | 0.55 | 콧방울 폭을 줄이지 않고 코 앞쪽 깊이와 밑면 높이 범위를 수축. 측면이 지나치게 납작해진 최대값 대신0.55 채택 |
| R2_MouthLine | 1 | 입술 부피/벌어짐 감소와 중앙/입꼬리 곡선의 국소 보정 |
| R2_JawContour | 1 | 앞쪽 아래 턱 폭7% 제어·주변 완화. 목 아래는 마스크로 보호 |

정면·양측면·사선을 직접 비교했다. 눈 개구가 길어지고 눈 아래 굴곡·코 돌출이 줄었으며 입/턱 윤곽도 바뀌었다. 현재 눈꺼풀 가장자리가 원화의 가는 선보다 두껍게 읽히고 입꼬리 곡선의 인상 차이가 남아03을 통과시키지 않았다. 눈썹/홍채·머리/색은04 이후의 요소이며 그 미제작을 기하 불합격 사유로 섞지 않는다. 수치적 눈알 접촉/모든 자기 교차·리그 변형, 실제 게임 크기·기기 검증은 하지 않았다.

**다음 한 작업은 현재 파일의 눈꺼풀 가장자리 단면/두께와 입꼬리 곡선 조정**이다. 보존된 제어와 현재 코0.55 상태를 이어 쓰고 전체 개구/콧방울 폭을 다시 일괄 확대·축소하지 않는다. 상·하 눈꺼풀/양 눈꼬리의 실제 면 고리를 확인해 국소 조정하고 정면·반대 측면에서 틈/돌출을 함께 확인한다. 03 통과 전04 색칠·전신·리그로 넘어가지 않는다.

5회 로컬 빌드이며 유료 제출은0이다. 앞의 두 명칭은 프로듀서가 폐기한 Meshy 후보01/02와 별개인 이번 로컬 시험이다. 폐기 생성물은 불러오지 않았다. 시험용.blend는 독립 재개방 검증 대상이 아니며 **현재 파일만** 검증했다. 보관 코드/설정은 당시 스냅숏으로 직접 실행용이 아니다. 재현 시 격리된 동일 폴더 구조에서 해당 코드/설정을 복원하고 원래 입력/상대 참조를 유지한다.

새 자료 두 개는 공식 MPFB CC0 그래픽 변위 원본이며 `source_registry.json`/source에 조회 경로·Git blob·SHA-256/원본 바이트를 보존했다. `nose-volume-decr` 이름만으로 내부 깊이만 줄인다고 판단하면 안 된다. 실제48정점 중 최대 변위가 현재 코끝 위치에서 +원천Z로 작용해 전방 돌출을 키웠다. angle-down은194정점에 작용했고 코 밑면을 내렸다. 이 결과로 두 자료 모두 제외했다. 기존 라이선스 원문을 참조하며 애드온 코드는 도입하지 않았다.
