## 실제 변경과 보존

입력은 이전 `face_surface_v1/viya_face_surface.blend` SHA-256 `f0eddaf89a763d9180f1efd2b99b45c347b70bc5c87111e02e047d318276765f`다. 이를 덮어쓰지 않고 `viya_face_surface_transfer.blend`를 만들었다. 기존 머리/눈4,455정점4,426면·모든 형태 제어/값·R4/코0.55·원래UV/별도UV/평가 제어 좌표와 양쪽 홍채PNG는 그대로다. **이번에는 형상을 바꾸지 않았다.** 이전R4 도입 전 개구56정점 고정 수치를 현재에 소급하지 않는다.

바뀐 것은 머리1024² 색 텍스처 한 장이다. 양 눈 각256²는 이전 파일과 바이트 동일하다. 원래 활성 머리 재질/이미지는 로컬 비교용으로 보존하고 새 활성 머리 재질과 이미지도 패킹했다. 활성 텍스처3개와 추가 비활성 비교 이미지가 있으므로 패킹 이미지 총수가3개뿐이라고 주장하지 않는다. 원래 파일/원본4장 바이트는 보존했다. `.gdignore`로 게임 임포트에서 제외했다.

`feature_registration.json`에 원본 정면의 양쪽 보이는 눈썹/속눈썹 경로와 역할을 기록했다. 양 눈썹 일부는 앞머리에 가려져 있다. 가려진 부분을 관찰값으로 꾸미거나 머리카락을 눈썹으로 전사하지 않았다. 보이는 원본 경로를 국소 곡선 좌표에 따라 RGB bilinear 샘플하고, 실제 눈꺼풀 면 고리/기존 표면UV로 배치했다. 원본 그림 자체를 변형/보정하거나 얼굴 전체에 정면 사진을 투영하지 않았다. 위치 계수0.00072 작업m/원본px는 **작성한UV 배치 선택**이지 보정된 두상 치수가 아니다. 새 원천 디테일을 복원하지 않았다.

가려진 눈썹 연장은 작성 가정이다. 첫 시험은 관찰 구간 주위를 잘라 보완선을 제외하면서 연결 높이/불투명도 차이와 빈틈이 생겼다. `trial01_disconnected_brow`에 설정/코드·색PNG/편집 파일·대표 렌더/탈락 근거를 보존했다. 현재는 관찰 구간의 실제 배치 끝점을 지나는 연속 보완선 아래칠과 불투명도0.85로 수정했다. 숨은 연장을 원본 측정값으로 승격하지 않는다. 보관한 첫 시험의 독립 재개방 PASS는 부여하지 않았다.

## 검수 결과와 남은 한계

정면·양 사선/양측면·55도 머리 비교와 별도 무조명3시점을 실제 렌더했다. 상단 속눈썹의 선·색은 더 강하게 읽히고 첫 시험의 눈썹 빈틈은 줄었다. **눈썹 조각과 보완선의 두께/불투명도 연결은 여전히 균일하지 않고 입선·표정도 원화와 다르다.** 입선/입술은 이번 변경 밖에 두었다. 머리카락 미제작 자체를 이번 텍스처 결함으로 세지 않으며 얼굴 전체 인상/닮음 통과로도 세지 않는다.

다음 한 작업은 현재 파일의 **눈썹 관찰/보완 경계 테이퍼와 원본 입선/색의 국소 전사**다. 기존 입 면 고리를 사용해 정면·양 사선/측면에서 표정을 대조한다. UV/홍채·R4/모든 형상 제어를 유지하고 형상 결함이 실제로 드러나면 해당03 부위만 검수한다. UV 전체 재배치/전체 얼굴 재생성·유료 참조 생성으로 돌아가지 않는다. 04 미통과 상태에서05/몸·총기/리그로 넘기지 않는다.

Blender4.3.2/Cycles32샘플·seed13/512×640·기존 카메라/검수 셰이더(무조명65%/Principled35%)를 유지했다. 기존 실제 렌더 표면의 위치·삼각형/UV 지문이 정확히 같아2048² 래스터 캐시를 재사용했으며, 캐시가 없으면 기존UV를 다시 래스터화한다. unwrap/새 모델 생성은 하지 않는다. 2배 표면 샘플 후1024²로 축소하고8출력px 거터를 유지했다.

최종 색 변화18,353px는 허용 눈/눈썹 표면과 필터/거터 영역 안에 있다. 재베이크의 다른21px에서 RGB 최대1 차이가 먼저 발견돼 원래PNG 바이트값으로 복원했고, **최종 허용 영역 밖 변경0**이다. 표면 전체 변경이 없었다고 과장하지 않고 `transfer_result.json`에 복원 전/후를 남겼다. 소스4장/입력 해시·모든 제어/UV·활성 패킹PNG SHA/양 눈PNG·독립 재개방 사선RGBA 픽셀 동일을 확인했다. 원래 머리 재질 보존/외부.blend 의존0/리그0이다.
