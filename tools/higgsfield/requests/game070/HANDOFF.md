# GAME070 — 제작세션 연결 보류

이번 두 후보는 모두 미채택이다. **게임에 연결할 새 run_sw PNG/시간표/총구/위상은 없다.** 현재 GAME069 활성리소스/35클립342프레임과 기존 run_sw11을 유지한다. 검토ZIP의 후보 영상/참조 이미지를 런타임 자산으로 가져오지 않는다.

반려 근거와 작업/비용은 README·evidence/candidate_01_review.json·candidate_02_review.json·cost_record.json을 따른다. 첫 후보의 가운데12장 시험은 미채택이며 납품 한 주기가 아니다. 유료2/최대2·실차감56/60·남은4로종료했고 자동세번째는금지다. 재개 시 실제 원격HEAD와 CURRENT/NEXT·최신 사용자 지시를 확인한다.

이후 유효한SW 일반보행이 별도 확보되면35클립중run_sw11만N장으로 바꿔 다른34클립331을 보존한다.200×248/root(100,248)/69×85.56·235/stride155·명목660ms/거리659.574468ms를 유지하고 실제 총구/반대지지발2쌍이상의독립위상을 납품받는다. main.tscn에서 SW반복/S↔SW·해제/정지·이동자동사격/총구·후진/피격우선/pause를 검수한다. 이번에는 이 연결/엔진검증을 수행하지 않았다.

후속 제작 검수에서 기존 SW11의 실제 `main.tscn` 재생을 확인했다. 현재 게임에서 교체용 자산을 받을 위치는 여전히 `run_sw`다. 다음 제작의 입력 구성과 실제 게임 기준 영상은 [입력 수정안](INPUT_STRATEGY.md)에서 확인한다.
