# GAME070 SW 달리기 입력 패키지

`sw_00_appearance.png`와 `sw_08_appearance.png`는 비야의 SW 외형과 고각 촬영 방향을 지정한다. 두 이미지에 같은 4배 확대와 여백을 적용했다. `s17_gait_timing.mp4`는 양발 지지와 회복의 순서를 지정한다. 영상의 S 방향 대신 SW 이미지가 보여 주는 화면 왼쪽 아래 방향으로 제작한다.

Higgsfield 기획세션의 현재 모델 메뉴에서 `image_references`와 `video_references`를 확인한다. `manifest.json`은 이 패키지의 파일 역할과 견적 확인에 쓸 설정을 담았다. 두 스틸은 `image_references`에, 영상은 `video_references`에 등록하고 `prompt.txt`를 사용한다. 세로 3:4는 이전 `auto` 설정에서 두 번째 후보가 가로로 나온 문제를 줄이기 위한 입력이다. 현재 계정의 견적과 해당 제작 승인 범위를 확인한다.

채택할 구간은 가까운 다리 지지에서 다음 가까운 다리 지지 직전까지다. 사이에 반대쪽 지지가 한 번 나오고, 회복과 체중 이동이 연속이어야 한다. 출력이 S로 돌아서거나 같은 다리가 연속으로 디디면 해당 주기는 제외한다. 유효한 주기에는 원천 시작·끝 프레임, 가중치, 발과 총구 기준 좌표를 기록한다.
