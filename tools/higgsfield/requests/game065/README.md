# GAME065 — 비야 E 전용 이동사격 제작 인수인계

GAME064의 기술 검수 뒤 진행하는 **E 한 방향의 새 전신 이동사격**이다. 원화 생성은 사용자가 지정한 기획/Higgsfield 세션에 인계하며 여기서는 제작 참조를 준비했다. 현재 게임은 사격 중에도 기존 E 달리기를 유지하는 경로이고, 새 전용 이동사격 이미지/리소스는 아직 없다.

- `PROMPT_KO.txt`: 기획 세션에 전달하는 제작/연동 기준.
- `PROMPT_EN.txt`: Higgsfield 영문 제작 프롬프트.
- `request_plan.json`: 현재 E47/대기/정지사격 참조 해시와 미실행 상태. 서비스 제출 API 스키마가 아니다.
- [깨끗한 동작 참조](../../../../docs/validation/GAME065_E_RUN_REFERENCE.mp4): 현재 채택된 E47을 중성 회색 위에서 재생한600×744/60FPS/198프레임/3.3초·명목5주기 영상. 신규 원화/새 사격 영상·실시간FPS 측정이 아니다.

참조 영상은 `tools/export_viya_run_reference.gd`가 원본 PNG를 바꾸지 않고 공통 ActorAssets의 실제 가변 시간표로 렌더했다. 카메라·몸/캔버스의 프레임별 변형이나 새로운 중간 자세를 만들지 않는다. 동작 참조와 캐릭터/총기 참조의 역할을 구분하고, 현재 모델의 입력 수/크기/가격/출력 형식을 확인한 뒤 지원되는 일부 입력을 선택한다.47이미지를 무조건 한 번에 업로드하라는 지시가 아니다.

새 출력이 오면 실제 입력 켜기/끄기·이동 사격↔달리기·정지·후진·방향 전환의 위상과 총구를 검증한 뒤 파생 리소스로 연결한다. 기존 E47을 새 이름으로 복사해 전용 사격 제작 완료로 처리하지 않는다. 원본/채택 E47·다른7방향·정지 공격·게임 발사 간격/피해·MP/스폰/보상을 유지한다. 제작/게임 연결/실기/최종 아트 승인을 구분한다.
