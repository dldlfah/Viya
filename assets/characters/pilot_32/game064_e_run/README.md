# GAME064 — VIYA E 달리기 파생 자산

사용자가 “게임에 반영해”라고 지정한 완성본을 기존 비야 전투 슬롯에 연결한 자산이다. **E 달리기47장**, 다른 동작197장의 기존 캐시 참조, 총32동작/244프레임이다. 원본208장·원본SpriteFrames와 ARTFIX001 캐시208장/리소스는 각각 기존 경로에 보존한다. 이번 통합에서 원화를 재생성하거나 흰 테두리 수정 작업을 반복하지 않았다.

새 PNG 임포트는 무손실·mipmap 없음·`process/fix_alpha_border=false`·premult_alpha 없음이다. 제작 단계에서 완성된 RGBA의 픽셀을 그대로 읽으며 원래 ARTFIX001의 임포트 설정은 변경하지 않는다.

## 모델과 출처

- 서비스/모델: Higgsfield, `hf_mult_motion_control`.
- 채택 작업 ID: `fbf2fd2d-8596-4ca4-87e7-875712a2f7c9`.
- 설정: `resolution=720p`, `use_free_gens=true`.
- 관측 원출력:720×1280,24fps,97프레임,4.041667초,RGB MP4.
- 원출력 SHA256: `103a6aa16585f5c6160f03c4373f8fcbba55283e655ff8dfcff371faded4d29d`.
- 원본 캐릭터 참조와 동작 참조를 사용한 채택본이며, 이전 시험 출력은 이 리소스에 연결하지 않았다.

알파는 모델의 네이티브 출력이 아니다. 제작 단계에서 녹색 배경 RGB 영상의 알파/경계색을 추출하고, 전체 영상에 동일한 변환을 적용해 준비했다. 해당 공정과 기술 검토는 `provenance`에 보존한다. 이 폴더의47PNG는 그 완성본의 복사이며 추가 원화 수정은 없다.

게임은 이동 거리/155로 위상을 누적하고 이 위상을 실제 duration 합계의 시간으로 바꾼다. 기존 공통 샘플러가 가변 구간에서 프레임을 선택하므로 모든47장을 균등시간으로 취급하지 않는다. 명목660ms와 이동 기준659.574468ms의0.0645% 차이는 전체 시간비율에 공통 적용되며 다른 방향의 stride를 바꾸지 않는다.

기준점은 모든 프레임에 동일한 캔버스 앵커이며 모델이 제공한 골격 루트가 아니다. 제작 단계에서 한 번 측정한 지면은 원영상y1108→캔버스y244.425163이다. 프레임마다 달라지는 알파 경계상자를 지면에 정렬하지 않는다. 마지막46→00은 연속 위상으로 연결하고 첫 프레임 끝 복제·핑퐁·교차 흐림·팔다리 조립/변형은 사용하지 않는다.60Hz에서는7.6ms 프레임 일부가 한 주기에 표시되지 않을 수 있으므로 한 주기의 화면 출력47장 전체 노출을 검증 조건으로 삼지 않는다.

## 게임 연결과 검증 경계

`data/presentation_slots.json`의 `viya_battle`과 `data/viya_motion.json`은 이 리소스를 가리킨다. `viya_presentation.gd`는 실제 선택된 프레임의 총구를 사용한다. 기존 정지 사격/다른 방향/전후진·방향 히스테리시스를 유지하며 전용 이동사격 원화를 새로 만든 것이 아니다. 불투명 임포트 복구는 기존 캐시197장과 새E47의 실제 PNG 경로를 사용한다.

Godot4.7.2 headless 임포트와 관련 네이티브417검사(오류0/누수0), 정적177파일/591참조·6계약·변이122거부가 PASS다. 실제 Linux X11/Mesa llvmpipe OpenGL의 생산 `main.tscn`에서834검사/329회 그리기를 통과했다. E160×1/60초 이동의47개 프레임·4회 반복, 해제→대기·SE 왕복·이동 자동사격·후진48단계·정지공격0→7·일시정지를 확인했다.329회 그리기는 Snapshot/cues를 바꾸지 않았다.

## 비용

이번 게임 통합은 새 생성0건·크레딧 소비0·새 결제/자동충전0이다. 채택 작업은 제작 당시0크레딧/무료생성1회를 사용했다. 앞선 보정 단계의 관측 차감은62크레딧이며 마지막 조회 잔액은966.25였다. 전체 이전 세션의 실제 차감액은 독립 확인되지 않았으므로 견적을 실제 비용으로 더하지 않는다. 이번 통합에서 잔액을 다시 조회한 것은 아니다.
