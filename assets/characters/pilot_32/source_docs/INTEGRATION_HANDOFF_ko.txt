3. 피격 시계와 방향
새 received cue 또는 HP 감소는 hurt_until=now+0.12를 만든다. 우선순위는 hurt > attack > run > idle다. 다른 pose에서 hurt로 진입하면 since=now이며, 같은 hurt 중 재피격은 종료 시각을 연장해도 since를 다시 시작하지 않는다. hurt_ne 6장·FPS 50·각 duration 1·loop=false는 120ms다. 상태가 계속되면 마지막 프레임을 유지한다.

각 새 cue에서 hurt_aim을 지우고 0이 아닌 방향만 저장하므로 마지막 cue가 우선한다. 마지막 0방향 cue나 cue 없는 HP 감소는 오래된 aim을 남기지 않는다. aim이 없으면 이동 중 displacement, 정지 중 전달 facing을 따른다. HP·피해·무적·cue와 실제 이동은 기존 게임이 소유한다.

고각 _draw_hero()의 텍스처 분기는 draw_texture_rect(...,false)이며 절차형 Forms.hero의 hurt_clock>.5를 PNG에 자동 적용하지 않는다. 피격 플래시·색 번쩍임·총구 효과는 자산에 굽지 않았고, 슬롯 연결만으로 절차형 깜박임까지 자동 보장된다고 보고하지 않는다.

4. 투영·표시·누적 구성
NE는 인덱스 7이다. 사선 siege_battlefield는 facing을 화면으로 투영한 뒤 8방향으로 선택한다. 월드 (1,-1)는 양의 zoom×(0.6420395219202062,-1.0321917922198198), 약 −58.1177도로 NE 섹터다. 정확한 화면 −45도와 동일한 월드축은 아니다. 발 위치만 투영하고 PNG는 50×62, pivot(0.5,1)로 직립 표시하며 회전·지면 Y압축·zoom·자동 반전은 없다.

frames/viya_hurt_ne_00.png~05.png는 공통 200×248 RGBA/sRGB다. 공통 crop [103,7,324,467], 배율 0.5304347826086957, 배치 [117,244], offset [41,4]를 적용했다. 원본 알파를 유지한 RGBa Lanczos 축소 뒤 완전 투명 RGB만 0으로 정리했다. 개별 프레임 크롭/배율/정렬·신체 변형·보간·재도색·배경 제거·알파 정규화는 없다. 아틀라스는 textures/viya_hurt_ne_atlas.png, 800×496의 4×2 배열이며 앞 6칸과 PNG가 일치하고 마지막 2칸은 투명하다.

viya_battle은 현재 빈 공용 슬롯이다. 조회는 동작_방향 → 방향 없는 동작 → idle_방향 → idle → default다. 모든 기본 상태가 파일로 준비되어도 실제 슬롯 연결은 수행하지 않았다.
