# GAME067 — SE 전용 전신 이동사격 원화 납품

**20장 RGBA 원화와 기술 자료를 납품했다. 게임 연결·최종 아트 승인은 별도다.** 현재 활성 리소스는 GAME066/33클립·298프레임 그대로다. 제작 세션은 이 패킷을 검수한 뒤 선택적 `run_fire_se` 한 클립을 기존 경로에 추가한다.

Seedance2.5 `omni_reference` 작업 `5b7cc811-ad50-4759-b8ea-8d1a40de7c77`의 RGB 원출력97프레임/24fps/864×1072에서 연속 원천10~29를 사용했다. 다음 대응30번은 제외했다. 모델이 요청한 느린2주기를 따랐다고 주장하지 않으며, 실제 출력에서 확인한 약20프레임 반복 한 주기를 납품했다. 기존 영상의 정지 자세를 따라가던 후보 대신 고정 SE 견착 이미지로 새 전신 동작을 생성했다. 팔다리 조립·핑퐁·이미지 시간 보간·끝 복제는 없다.

- 캔버스200×248, root/pivot(100,248), 표시69×85.56. 한 고정 scale200/864·translation(0,-0.148148148148)이며 프레임별 bbox 재정렬은 없다.
- RGB의 실제 청록색 키에서 불투명 내부/경계 혼합색을 분리한 파생 RGBA다. 서비스 네이티브 알파가 아니다. 원본과 생성 원출력은 별도로 보존했다.
- 실제 원천 PTS 간격을 명목660ms로 비례 재생한다. 기본속도235/stride155에서659.574468ms다. 각장 source/nominal/base-speed시간은 `provenance/frame_timing.csv`에 있다.
- 새 총열 끝20개를 새 PNG에서 독립 측정했다. `muzzle_coordinates.csv`와 표시 비교를 확인한다. 기존 E/SE 총구를 복사하지 않았다.
- `phase_alignment.json`의 독립 2D 장화 비교 권고 위상은0.819949494949495다. 기존3/11을 그대로 복사하지 않았다. 원천 이동사격의 다리 벌림/발 위치는 SE18과 차이가 있으므로 이 수치를 픽셀 단위 접지 일치·무미끄러짐 증명으로 삼지 않는다. 실제 on/off 전환은 제작 세션의 main.tscn 검수가 필요하다.

`provenance/art_review.mp4`는 현재 SE18과 새20장을 같은 거리 위상으로 재생하고69×85.56전환을 보여 주는 아트 분석 영상이다. 실제 게임 캡처/FPS 검증이 아니다. 접지/크기/총/손·캐릭터 비교 이미지는 같은 폴더에 있다. 제작 기록/후보 반려/실패/모델·입력·견적·원출력 해시는 `production.json`과 `tools/higgsfield/requests/game067/evidence`에 보존한다. 전체 관측 차감158.25/최종조회657크레딧, 채택 생성28크레딧이며 새 결제·충전·요금제 변경0이다.
